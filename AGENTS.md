# Dialoid: организация работы

- Чаты используются для обсуждения идей и тестирования. Исполнение многосоставной работы веди задачами по `docs/tasks/README.md`.
- Используй три роли исполнителей из `.codex/agents/`: `dialoid-core-developer`, `dialoid-godot-developer`, `dialoid-technical-artist`. Можно запускать несколько экземпляров каждой роли на независимые задачи с разными областями файлов.
- Назначай конкретные разрешённые файлы; не допускай двух писателей одного файла в общей рабочей копии. Основной агент отвечает за интеграцию и общую проверку.
- Кураторы перечислены в `docs/agents.md`. Автор и независимый ревьюер должны быть разными экземплярами. Не запускай всех кураторов на каждую задачу: выбирай по области.
- Для визуальной работы источник истины — `docs/art/ART_DIRECTION.md` и указанные там утверждённые изображения. Проверяй результат под игровой камерой с настоящим UI.
- Сохраняй чужие незавершённые изменения. Покупки и новые расходы без действующего разрешения не выполняй. Секреты не выводи и не коммить.
- Рутинные действия в пределах поручения выполняй самостоятельно. Спрашивай владельца только при реальной необходимости его решения.

## Генерация изображений

- Перед работой с концептами, задниками, Venice или передачей иконок GPT прочитай [.agents/skills/dialoid-venice/SKILL.md](.agents/skills/dialoid-venice/SKILL.md).
- Решение владельца: **все задники и концепты — Venice; иконки затем подхватывает GPT по утверждённым референсам**. Не заменяй сервис из-за доступности встроенного генератора.
- Рабочий инструмент — `spike-3d/tools/venice.ps1`. Он и `.env` локальные и не входят в git; если их нет в worktree, найди основную копию через git common-dir/worktree list, как описано в скилле. Если арт-гайда нет в ветке, прочитай актуальный `docs/art/ART_DIRECTION.md` в основной копии. Секреты не копируй и не выводи.
