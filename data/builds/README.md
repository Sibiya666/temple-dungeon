# Эталонные билды

Демо-сборки для владельца и регрессионный набор баланса (§12, §15). Все шесть основных билдов — 60 уровень: 59 пассивок, асцендант с 4 notables, 5 слотов, скиллы 20 уровня со всеми 20 очками дерева. Keystones в основных билдах нет: тест keystones (§15.6) добавляет их к эталонам. Ротация — приоритетный список: первый доступный скилл, генераторы в конце. Спендер тратит ресурс, как только его хватает. Билды проверяет `core/Dialoid.Core.Tests/Content/ReferenceBuildTests.cs`.

Основные билды — тематические: каждый держит свою идею (доминирующий скилл и тип урона). Поэтому они **не потолок класса**. Потолок лежит в `parity/` (см. ниже). Паритет классов (§15.10) считается по файлам `parity/` на всех трех уровнях.

## Воитель (двуручный топор)

- **`warrior_berserker_whirlwind` — «Кровавый Берсерк-Вихрь».** Вихрь на кровотечении, основной урон — физический. Ротация: Боевой клич → Рывок → Сокрушение → Вихрь, Метательный топор добирает Ярость. Ключевое: Вихрь ярости и Неутолимый, Без оглядки, Кровавый пир; ветки «Мясник», «Открытые раны», «Кровавая баня»; в дереве Вихря — «Неистовое вращение», «Ураган клинков» и «Тысяча порезов».
  - **Внимание:** с Вихрем ярости Вихрь нельзя ставить в ротации выше Сокрушения. Вихрь выше 50% Ярости ничего не стоит, поэтому канал не кончается, и остальные скиллы не применяются: Сокрушение и Топор — 0 раз за 60 с. Это не ошибка движка, а следствие приоритетной ротации.
- **`warrior_thunderer_crush` — «Громовержец Сокрушение».** Сокрушение, превращенное в молнию («Громовой молот»), с копией «Землетрясения». Ротация: Боевой клич → Рывок → Сокрушение → Вихрь, Рассекающий удар генерирует. Ключевое: Разряд, Статический заряд, Буря в жилах, Цепной удар; «Грозовой фронт», «Цепная реакция», «Неуемная ярость».
- **`warrior_fire_cleave_crit` — «Огненный Громовержец».** Это огненный вариант Громовержца, а не чистый «Огненный клинок крит» из §12. Рассекающий удар в одну цель («Точный удар», «Кромка») с конверсией в огонь («Раскаленный клинок»), огненный Вихрь и «Огненный след» Рывка. Рассекающий удар лидирует слабо: 29% против 24/24/23%. Ротация: Сокрушение → Вихрь → Боевой клич → Рывок, Рассекающий удар генерирует. Ключевое: Разряд, Цепной удар, Заземление, Буря в жилах; «Безжалостный удар», «Убийца», «Испепеление», «Пекло».
  - **Почему не «чистый» огненный клинок.** У Воителя нет асцендантской поддержки огня (вопрос владельцу). Берсерк держит Рассекающий удар выше следующего скилла в 1.25 раза только с двумя notables, которые ничего не дают (Неутолимый и Без оглядки, вклад 0%). С любым полезным четвертым notable (Боевой транс, Вихрь ярости) лидером становится Вихрь (44–49%). Громовержец с требованием 1.3 не поднимается выше 29% против 24%. Рассекающий удар — генератор и только заполняет паузы между спендерами.

## Чародей (посох)

Шесть скиллов на пять слотов, поэтому все три билда Чародея делят большую часть набора (Искра, Мерцание, Шаровая молния и Метеор есть во всех трех). Различие — в спендере-лидере, развилках деревьев и асценданте.

- **`sorcerer_pyromancer_fireball` — «Огненный шар + поджог, Пироман».** Огненный шар со «Сжатием» и поджогом. Метеор и Шаровая молния тоже огненные («Солнечный шар»). Ротация: Мерцание → Метеор → Шаровая молния → Огненный шар, Искра генерирует. Ключевое: Распространение, Пепел, Вечный огонь, Жар души; «Испепеление», «Пекло», «Архимаг», криты заклинаний.
- **`sorcerer_cryomancer_ice_lance` — «Ледяное копье, Криомант».** Ледяное копье на критах с пирсом, Метеор переведен в холод («Ледяной метеор»). Ротация: Мерцание → Метеор → Шаровая молния → Ледяное копье, Искра генерирует. Ключевое: Раскол, Хрупкость, Северное сияние, Ледник; «Лютая стужа», «Ледяное сердце», «Чародейская точность», «Разящая мысль».
- **`sorcerer_spark_hybrid` — «Грозовой Криомант: Шаровая молния».** id файла сохранен из плана. На деле это билд Шаровой молнии: она дает 70%, Искра как генератор — 15%. Огня в билде нет: Метеор холодный («Ледяной метеор»), огненных пассивок и узлов нет. Ледяное копье («Ледяная глыба») применяется пару раз за бой и занимает пятый слот. Ротация: Мерцание → Метеор → Шаровая молния → Ледяное копье, Искра генерирует. Ключевое: Раскол, Ледяная броня, Хрупкость, Северное сияние; «Грозовой фронт», «Цепная реакция», криты заклинаний.
  - Вариант через «Грозовой шар» (Огненный шар становится молнией, §10.3) слабее на ≈ 12%: 4046 / 14110 против 4343 / 16818. Вариант, где Искра дает ≥ 25% урона, слабее на 35–40%. Оба варианта — кандидаты для задачи 10.

## Известные более сильные сборки вне набора

- **Берсерк-Сокрушение** (`parity/warrior_l60`): 35111 тренировочный DPS, 29694 по рою, выживание 17.5 с. Это в 2.2 раза больше лучшего эталона Воителя (15648). Схема: Неутолимый + Боевой транс + Без оглядки + Кровавый пир, Сокрушение 85% урона. Транс держит Ярость на 100, Сокрушение на 100 Ярости платит здоровьем, и Ярость остается полной («Безумие»). Без Неутолимого тот же билд дает 18569 DPS и живет 63 с.
- **Keystones** (в наборе запрещены, кандидаты для теста §15.6):
  - Аватар огня в огненном Рассекающем ударе дает 100% огня;
  - Кровавый пакт вместе с Аватаром у Пиромана: стоимость превращается в перезарядку, Шаровая молния и Искра уходят в огонь. Это +20% к цели поиска, но выживание падает до 28 с.
- **Чародей без темы** (`parity/sorcerer_l60`): 10123 тренировочный DPS против 8593 у эталонного Пиромана.

## Служебные билды

- `parity/<класс>_l1.json`, `_l20.json`, `_l60.json` — сильнейшая найденная сборка класса на 1, 20 и 60 уровне: только тренировочный DPS, без темы и без keystones. По ним считается паритет (§15.10): на 1 уровне 33.5 против 20.4 (×1.65), на 20 — 3660 против 2149 (×1.70), на 60 — 35111 против 10123 (×3.47).
- `attributes/<класс>_no_attribute_nodes.json` — копия эталона (Воитель — `warrior_thunderer_crush`, Чародей — `sorcerer_pyromancer_fireball`). Каждый атрибутный узел, без которого билд остается связным, заменен соседним малым узлом; бюджет очков тот же (§15.9). Атрибутные узлы вокруг стартов и между ветками дерева остаются, потому что без них отваливается часть билда. Поэтому заменено только 4 из 16 и 3 из 18 узлов.

## Мертвые очки

В деревьях скиллов по 15–20 узлов, а очков 20, поэтому часть очков ничего не дает. Примеры, при которых DPS и выживание не меняются:
- Боевой клич: «Звон в ушах» до 4 очков;
- Метеор: «Кратер» 3 очка;
- Мерцание: защитные узлы («Неуловимость», «Остаточный образ», «Фазовый барьер»), когда выживание уже на капе 180 с;
- `sorcerer_spark_hybrid`: дерево Ледяного копья.

## Как билды получены

Билды собрал оптимизатор `tools/BuildOptimizer`, локальный поиск на симуляторе (заголовок `Program.cs` описывает его целиком). Рецепт каждого билда лежит в `tools/BuildOptimizer/rebuild_references.sh`.

Цель поиска — √(DPS на «Тренировочном» × DPS пака на «Рое»). Ее можно умножить на `(выживание / 180)^w` (`--survival-weight`); для текущего набора w = 0, потому что эталоны 60 уровня живут долго.

Ограничения (штрафы):
- каждый скилл ротации применяется хотя бы раз;
- доминирующий скилл архетипа дает урона не меньше чем в m раз больше любого другого;
- доминирующий тип урона не ниже заданной доли;
- запрет узлов, которые противоречат теме (например яд или чужая стихия);
- keystones запрещены.

Для билдов `parity/` используется только тренировочный DPS, без темы. Задача 10 может пересобрать набор после каждой итерации баланса.

## Загрузка и экспорт

Файл — это JSON билда в формате `BuildCodec.ToJson` (snake_case).

```csharp
var data = DataLoader.Load("data").Data!;
BuildCodec.TryFromJson(File.ReadAllText("data/builds/warrior_thunderer_crush.json"), data, out var build, out var error);
var code = BuildCodec.Export(build!);                      // строка «DLD1:…», ее можно переслать
BuildCodec.TryImport(code, data, out var copy, out error); // обратно в Build
File.WriteAllText("my_build.json", BuildCodec.ToJson(copy!));
```

В тестах билды загружает `ContentHarness.LoadBuild("warrior_thunderer_crush")`, путь указывается без `.json`. `TryFromJson` проверяет id. Законность билда проверяет `BuildRules.Validate`.
