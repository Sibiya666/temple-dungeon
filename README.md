Диаблоид (ARPG в духе Diablo/PoE2/Last Epoch). Сейчас в репозитории только `Dialoid.Core` — чистая C#-библиотека правил игры без Godot.

## Ядро: как запустить тесты

```bash
dotnet test core/Dialoid.sln
```

Требуется .NET SDK 8 или новее (цель сборки — `net8.0`, на новых рантаймах включён `RollForward=Major`). Предупреждения компилятора считаются ошибками.

## Архитектура ядра

Слои `Dialoid.Core` (в порядке сборки, верхние опираются на нижние):

1. **Stats** — статы, модификаторы Flat/Increased/More/Override, формула, граф зависимостей `per`.
2. **Data** — загрузка JSON из `data/`, валидатор с русскими сообщениями (файл, id, причина).
3. **Effects / Character / Passives / Skills** — эффекты и механики, билд и его правила, дерево пассивок, деревья скиллов.
4. **Combat** — урон, конверсия, митигация, недуги.
5. **Mechanics** — механики классов и ключевых узлов (C#, подключаются по id из данных).
6. **Simulation** — детерминированная симуляция боя («среднее» и случайный режим), использует реестр механик.
7. **Builds** — экспорт и импорт билда: код `DLD1:` + base64url(gzip(JSON)), JSON в snake_case.

Новый скилл или узел, собранный из существующих эффектов, условий и механик, добавляется только данными, без правок C#.
