## Доказательства

- `core/Dialoid.Core/Simulation/LiveTypes.cs:33`: `LiveState` передаёт `Life`, но не максимум здоровья героя. Поле `TargetLifeMax` (строка 69) относится к целям, не к герою.
- `core/Dialoid.Core/Simulation/SimState.cs:6,10`: реальный максимум — `SimState.LifeMax`, однако сам класс `internal`.
- `core/Dialoid.Core/Simulation/CombatEngine.cs:326`: каждый шаг `TickLife` присваивает `_s.LifeMax = ev.Evaluate("life", default, _conditions).Value`. Максимум зависит от текущих боевых условий и баффов.
- `core/Dialoid.Core/Simulation/LiveFight.cs:24,48`: движок закрыт в `private _engine`, доступ к `Sim` — `internal`. `BuildState` (строки 218–230) копирует `s.Life`, но не `s.LifeMax`.
- `core/Dialoid.Sandbox/TrainingRoom.cs:92–111`: публичный `State` берёт снимок боя и меняет только отображение слотов; максимум героя не добавляет. Сам `_fight` закрыт.
- `core/Dialoid.Sandbox/SandboxSession.cs:428,559` предоставляет `CharacterLines`, но `core/Dialoid.Core/Explain/CharacterSheet.cs:20` считает их с `NoConditions.Instance`. Это лист персонажа, а не актуальный максимум из боя; подмена им некорректна при изменении максимума баффами.

## Первоначальный результат исследования (до исправления Core)

Корректного публичного источника актуального максимума героя в текущем Core/Sandbox не найдено. По текущему дереву нельзя установить, был ли контракт удалён или ещё не добавлен; установлено именно его отсутствие сейчас.

Два C# файла оставлены без изменений. Ошибки сборки остаются: безопасного патча в назначенной области нет. Нулевое, константное, текущее здоровье, максимум цели, статический лист персонажа и reflection вместо реального источника не использованы.

Для разблокировки владельцу Core требуется передать `s.LifeMax` в публичном снимке `LiveState` из `LiveFight.BuildState` (с проверкой изменения максимума в бою). Это предложение вне разрешённой области; здесь оно не реализовано. После такого изменения существующие обращения HUD можно проверить общей сборкой.

Сборка и тесты не запускались по прямому указанию владельца. Коммитов нет. Изменена только эта карточка; чужие незавершённые изменения сохранены.
