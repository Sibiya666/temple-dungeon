# TASK-tower-inventory-nodes: реальные ноды инвентаря
Статус: done
Исполнитель: dialoid-core-developer; dialoid-godot-developer после контракта Core; интегратор — основной агент.
Цель: слева инвентарь активностей, справа инвентарь намазок, в центре башня.
Основа: уточнение владельца 2026-11-01. Активности одного типа и ранга стакаются; получившая намазку занимает отдельную ноду и больше не стакается. Установка переносит один экземпляр, снятие возвращает тот же экземпляр с намазками. Намазки стакаются по типу.
Зависимости: TASK-tower-icons-frames
Разрешённые файлы: Core исполнитель core/Dialoid.Core/Tower/ActivityInventory.cs и core/Dialoid.Core.Tests/Tower/ActivityInventoryTests.cs; Godot исполнитель game/Ui/Tower/TowerBoardView.cs; интегратор core/Dialoid.Core/Tower/TowerAssembly.cs (internal перенос FloorSpec), game/SelfTest.Tower.cs и эта карточка.
Не входит: реальные дропы и сохранения, новый баланс, 3D-этажи, новые расходы на генерацию.
Критерии готовности: ноды с иконкой/количеством; реальные перемещения без копирования модов/пополнения валюты; намазка по выбранной активности либо установленному этажу/башне; смена ранга не клонирует инвентарь; раздельные ноды после намазки; стеки валют; клавиатура/геймпад; 720p.
Проверка: Core тесты переноса/возврата/модификаций/очищения/разделения; сборка game; реальные кадры и tower selftests; независимое техническое и UI ревью.
Ревью: dialoid-tech-reviewer, dialoid-ui-curator.
Результат: ActivityInventory хранит экземпляры и точные FloorSpec; активность переносится по одной, прежняя возвращается, модифицированная навсегда отдельная. Слева сетка нод активности с рангом/количеством, справа сетка намазок с количеством; описание цели и операции закреплено, установка/снятие доступны кнопками. Тестовый seed по5каждого типа/ранга и по20валюты, только один раз на процесс.

Проверено интегратором: Core Tower175/175 (7 новых inventory-тестов), сборка game0ошибок (3NU1900 аудитNuGet), реальный Godot/Vulkan tower5/5 (icons,crafting,inventory-transfer,open-close+panels),720p. Кадры и лог: docs/art/tower/2026-11-01-frames/; inventory-singleton.png показывает отдельный очищенный экземпляр рядом со стаком. Независимые технический01a195f6-9e42-7060-9071-4e060af77ec0 и UI/арт01a195f9-1643-79d0-a79a-0f4eb994a133 — APPROVE для реализованной части.

История этапа: перемешивание первоначально было отключено из-за несовместимости старого генератора с владением экземплярами. Продолжение по последним решениям владельца — TASK-tower-shuffle-completion: пустой старт, заполнение только по кнопке из инвентаря, сохранение установленных активностей. Текущая реализация и её финальная приёмка описаны в этой отдельной карточке. Реальных дропов, сохранения и игровых этажей по-прежнему нет. Коммиты не создавались.
