# Недостающие иконки Воителя и Отступника

Статус: done.
Поручение владельца: обновить недостающие иконки мечника; уточнение «для обоих» — Воитель и Отступник.
Объём: 87 узлов Воителя, 104 узла Отступника и 6 навыков Отступника — 197 индивидуальных изображений. Существующие 17 узлов Cleave и готовые иконки навыков Воителя сохраняются.
Производство: GPT image_gen по одному утверждённому оригиналу Venice, отдельный запрос на каждый ID; промпты/происхождение/мастера в docs/art/icons/2026-11-01-swordsmen/. Runtime PNG в game/Ui/Art/Icons/skill_nodes/ и skills/.
Исполнители: технические художники — отдельные JSON-задания для каждого класса; интегратор — генерация, экспорт, GameIcons, проверка и отчёт. Независимое арт/UI-ревью после генерации.
Не входит: восстановление архивных механик Отступника в активном каталоге, новые боевые эффекты и изменение баланса. Иконки архивных ID могут быть подключены в каталог ресурсов без изменения доступных классов.
Критерии: все 197 ID имеют самостоятельные читаемые изображения без подмены общими символами, точная runtime-привязка, проверка 64/32/24 px, реальные игровые кадры и независимый просмотр.

Результат: 197/197 новых изображений выбраны и экспортированы; пропусков и дублирующих runtime-хешей нет. 17 прежних Cleave сохранены, итого каталог содержит 208 отдельных узлов и 6 новых навыков AP. GameIcons использует точные пары skill_id/node_id и проверенные алиасы копий. Неизвестные ID не открывают произвольные пути. Активные классы и игровые правила не менялись.
Арт-приёмка: Воитель 87/87 APPROVE (Faraday), Отступник 6 навыков + 50 первых узлов APPROVE (Dirac), последние 54 узла APPROVE (James). Замечания устранены 14 выбранными ревизиями от того же исходного Venice-оригинала. Код/экспорт/каталог: независимое ревью Fermat APPROVE.
Техническая проверка: финальная сборка 0 ошибок/предупреждений, Godot SWORDSMEN_ICONS_OK — 208 точных node PNG 64×64 + 6 skill PNG, unsafe IDs rejected, active catalog unchanged. Целевой skills selftest 6/6 PASS; полный общий selftest не запускался.
Доказательства: [README и все листы](../art/icons/2026-11-01-swordsmen/README.md), manifest.json с SHA256, три независимых review JSON и итоговые игровые кадры в in-game/.
