# Индивидуальные иконки всех узлов навыков

Статус: ready — производство ассетов не выполнено.
Основа: постоянное правило владельца — каждый новый навык и узел получает собственную иконку без отдельного напоминания.
Область: missing IDs в docs/art/icons/node-art-backlog.json; производство исходников GPT от утверждённого Venice-эталона, runtime PNG, назначение в GameIcons, реальные кадры и проверка.
Текущее состояние: 217 узлов в активных деревьях, у 17 узлов cleave есть индивидуальные иллюстрации. У остальных 200 остаются общие знаки эффектов: это технический fallback, не готовые иконки. Раскладки деревьев завершены отдельно; ассеты не объявляются готовыми.
Новые навыки будущих пяти групп автоматически должны включать собственную иконку навыка и иконки всех его узлов в ту же задачу; не добавлять ещё один скрытый долг.
Критерии: у каждого ID назначен смысловой PNG, нет подмены общим знаком; сохранены референс/промпт/исходник; читаемость 64/32/24 px, проверка настоящего UI, независимое UI/арт-ревью. Один рисунок на все ранги узла, рамки и числа отдельно.
