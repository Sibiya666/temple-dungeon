# Граф дерева отдельного навыка

Статус: done
Основа: владелец подтвердил реализацию графического дерева вместо списка. Спецификация: docs/superpowers/specs/2026-10-31-cleave-radial-tree.md.
Исполнитель: Godot-агент; интегратор — основной агент.
Область: SkillsPanel.Graph.cs, SkillsPanel.cs, SkillsPanel.Catalog.cs; интегратор — целевые проверки, preview-сцена, эта карточка и отчёт с кадрами.
Цель: в окне K виден граф с иконками всех узлов, требованиями и рангами; узел выбирается мышью и геймпадом; выбранный узел показывает действие и ограничения. Редактирование только через действующие команды Sandbox; предварительный просмотр ничего не меняет.
Проверка: сборка, целевые skills selftest, зависимости и отказ незаконного вложения, просмотр без слота, реальный оконный кадр.
Не входит: баланс, новые боевые поля, восхождения, чужие незавершённые правки main.

Результат: список заменён графом и для установленного навыка, и для предварительного просмотра. Cleave имеет ручную раскладку 17 узлов; остальные навыки — радиальную раскладку по глубине требований. Все связи строятся из данных. Выбор узла открывает описание, ранги, требования, взаимоисключение; вложение и снятие — отдельные команды. Масштаб и выбор сохраняются при обновлении. Восхождения не менялись.

По обратной связи владельца прежние толстые жёлтые круги полностью заменены отдельной отрисовкой SkillTreeGraphView: иконки заполняют квадратную внутреннюю область, рамки 1 px, холодные приглушённые связи и тёмная плашка ранга. Общий TreeView пассивок не изменён.

Проверка: dotnet build — 0 ошибок/предупреждений. Godot skills selftest — 5/5 PASS: каталог, слоты, граф, легальность изменения очков и числа. Целевой прогон не является полной приёмкой. Проверены отсутствие изменения билда в preview, все 17 иконок и связи, объяснение альтернативы, кнопка вложения и сохранение масштаба. Физический геймпад не проверялся.
