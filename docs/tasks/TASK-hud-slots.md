# TASK-hud-slots: назначенные скиллы без активного боя

Статус: review
Исполнитель: dialoid-godot-developer, текущий экземпляр чата
Цель: выбранный в K скилл остаётся в HUD при невалидном билде; слоты компактнее.
Основа: поручение владельца, AGENTS.md, docs/art/ART_DIRECTION.md.
Зависимости: общая последовательная сборка и игровая проверка основным агентом.

Разрешённые файлы:
- game/Ui/Hud/HudData.cs
- game/Ui/CombatHud.cs
- game/Ui/Hud/SkillSlotView.cs
- game/SelfTest.Hud.cs
- docs/tasks/TASK-hud-slots.md

Не входит: Main, Room, фоны окон, остальные файлы, коммиты, полный import и сборка в параллельной рабочей копии.

Критерии готовности:
- Новая сессия warrior без оружия: назначение cleave показывает имя и иконку; подсказка содержит нарушения TrainingRoom.
- При отсутствии боя стоимость и перезарядка не вычисляются из базового определения скилла.
- Замена, очистка и повторное назначение обновляют имя, иконку и подсказку без старых данных.
- Слоты имеют минимальный размер 72×64 при иконке 32×32.

Проверка:
- Выполнено: git diff --check для четырёх разрешённых C# файлов, без ошибок.
- Добавлен шаг hud.assigned-slots-without-fight: отдельные SandboxSession и TrainingRoom, подписка на изменения, cleave → crush → пусто → cleave; исходная игровая сессия не меняется.
- Основному агенту: последовательно собрать game/Dialoid.Game.csproj и выполнить HUD self-test, включая новый шаг и hud.components-match-state.
- В игре: новый воитель без оружия, K → cleave, проверить иконку, имя и причину при наведении; заменить и убрать скилл. Проверить клавиатуру и геймпад, длинные названия, перезарядку и отсутствие пересечений при 72×64. Сделать кадр под игровой камерой с настоящим UI.

Ревью: независимый dialoid-ui-curator; общая проверка основным агентом.

Результат: сохранены исходные незавершённые изменения автора в модели HUD, fallback и размерах. Уточнён ключ кеша подсказки (учитывает имя), добавлено свойство IconTexture для проверки фактической текстуры и регрессионный сценарий.
