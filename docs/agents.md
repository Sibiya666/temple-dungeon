# Агенты Dialoid

## Исполнители Codex

| Роль | Область |
|---|---|
| `dialoid-core-developer` | C#, Core/Sandbox, данные, правила боя и тесты |
| `dialoid-godot-developer` | Сцены, управление, HUD, анимации, интеграция |
| `dialoid-technical-artist` | Модели, материалы, текстуры, иконки, VFX и оптимизация |

Определения находятся в `.codex/agents/*.toml`. Каждая роль может иметь несколько экземпляров для независимых задач. Чаты служат для обсуждения и тестирования; [правила задач и параллельной работы](tasks/README.md) определяют исполнение, границы файлов и приёмку. Автор и ревьюер — разные экземпляры.

## Кураторы и ревьюеры

Файлы агентов лежат в `.claude/agents/`. Каждый читает документ, план или скриншоты и возвращает вердикт APPROVE (утвердить) или REVISE (доработать).

| Агент | Роль | Когда звать |
|---|---|---|
| `arpg-design-reviewer` | Эксперт по ARPG: боевая математика, билды, кривая силы | Классы, скиллы, атрибуты, пассивки |
| `dialoid-mechanics-designer` | Геймдизайнер механик: ощущение в руках, пересечения систем | Классы, скиллы, асценданты, keystones, недуги |
| `dialoid-tech-reviewer` | Технический архитектор: стоимость в коде, архитектура ядра | Любой дизайн-док и план перед реализацией |
| `dialoid-art-curator` | Арт-директор: стиль, читаемость боя, ассеты, лицензии | Визуал, подборки ассетов, скриншоты |
| `dialoid-loot-economy-designer` | Дизайнер лута и экономики: предметы, крафт, валюты | Лут, награды, валюты башни, пресеты |
| `dialoid-encounter-designer` | Дизайнер врагов и встреч: роли монстров, боссы, сложность | Монстры, боссы, этажи башни, ранги |
| `dialoid-ui-curator` | Куратор интерфейса, хранит видение UI (гамма D2, удобство D4, геймпад наравне с мышью): подсказки, числа, нажатия, русские тексты | Экраны, окна, HUD, подсказки, управление, макеты и скриншоты |

Обычные связки:
- **Класс или скилл:** arpg-design-reviewer, dialoid-mechanics-designer, dialoid-tech-reviewer.
- **Башня и эндгейм:** dialoid-encounter-designer, dialoid-loot-economy-designer, dialoid-tech-reviewer.
- **Визуал и сцена:** dialoid-art-curator, dialoid-ui-curator.

Новая роль Codex добавляется файлом в `.codex/agents/` и строкой в этот документ. Определения `.claude/agents/` сохраняются для Claude; они не заменяют TOML-роли Codex.
