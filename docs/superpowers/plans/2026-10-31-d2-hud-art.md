# Первый проход оформления HUD в духе D2

**Основа:** утверждённая спека `../specs/2026-10-30-dialoid-combat-hud-design.md`, просьба владельца заняться оформлением 2026-10-31.

**Цель:** заменить технические поверхности на тёмный камень, потемневшую бронзу и резные рамки; показать результат в настоящем Godot на существующей сцене комнаты.

**Разделение файлов:** владелец 3D-комнаты продолжает исправлять Task12 в `training-room-3d`. UI добавляет только автономные файлы `game/Ui/Art/`; существующие `CombatHud`, `Ui/Hud/*`, `WindowHost`, навигация, hitboxes и safe-area не меняются. Для сборки используется отдельный checkout на базе `feat/training-room-3d`.

**Границы первого прохода:** оформление поверх существующих данных и геометрии комнаты. Шары, смена раскладки А/Б и игровые панели D2 остаются отдельной реализацией по HUD-спеке. Никаких фиктивных шкал здоровья или ресурса. Арт оригинальный, SVG и процедурный камень; внешние зависимости и скачивание ассетов не нужны.

- [x] Создать `RoomHudTheme.cs`: палитра, стили рамок и тема Godot с API для будущего подключения к компонентам.
- [x] Создать оригинальные SVG-рамки и декоративный слой, не перехватывающий ввод.
- [x] Создать отдельную сцену `HudArtPreview.tscn`: загрузить настоящую комнату и подключить тему только в этой сцене. При запуске сохранить скриншот по явно заданному аргументу.
- [x] Собрать проект на базе комнаты, проверить загрузку сцены и отсутствие ошибок Godot, осмотреть реальный скриншот.
- [x] Проверить с UI-куратором и арт-куратором, показать владельцу и передать автономные файлы владельцу комнаты для последующего подключения.

**Проверки:** размеры/MouseFilter декоративного слоя, состояние слотов и чисел не меняются; сравнение снимков до и после в одинаковом разрешении. Юнит-тесты пиксельных оттенков не нужны; сборка и проверка сцены покрывают ошибки ресурсов и API.

Результат: арт-куратор и UI-куратор — APPROVE для первого opt-in preview. Интеграция в существующий HUD остаётся владельцу 3D-комнаты после fix/review Task12. Пакет проверен как на базе комнаты, так и сборкой основной ветки.
