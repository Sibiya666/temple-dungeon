## 1. Зачем это и что считается успехом

Вся игра — башни из 5 этажей. Ранги 1–2 почти без модов, и это 40% прокачки, поэтому новизна там идет от ростера врагов (башня 6.2). Дальше враги — то, во что упирается билд на стене ранга, и то, что меняют моды башни.

**Успех.** Игрок с одного взгляда понимает, кто в стае опасен и кого бить первым. Крупный урон всегда читается заранее, смерть объяснима («стоял в круге», а не «умер от невидимого»). На стене ранга игрок проигрывает потому, что билд слаб, а не потому, что класс или архетип бессилен против ростера. Каждый тип этажа ощущается своим (башня 4.7).

### Цели
1. Модель монстра в данных: роль, здоровье, защита, атаки с телеграфами, поведение.
2. Роли в стае и состав стай по типам этажей.
3. Элиты: чемпионы и редкие вожаки, каталог аффиксов, ввод по рангам.
4. Боссы и убер-боссы: контракт, фазы, окна урона, пул по рангам.
5. Кривая силы монстров и ступени рангов 1–15.
6. Правила справедливости: телеграфы, всплеск урона стаи, скорость, сопротивления и броня, тьма, недуги.
7. Первый контент **[Владелец]**: Рогачи (рядовые), Рыцарь ада (вожак), Баал (босс).

### Не цели
- ИИ, навигация, анимации, 3D-модели — к живому бою и визуалу; здесь требования к ним.
- Полный ростер на 15 рангов. Здесь структура, правила и первые три врага.
- Миньоны игрока, мультиплеер. Финальные числа.

### Анти-цели (провал, даже если все «работает»)
- **Ваншот без предупреждения**, в том числе от стаи, а не одного удара.
- **Губки здоровья**: сложность только в «+здоровье».
- **Класс или архетип беспомощен** против базового ростера или аффикса ранга (моно-тип урона, ближний бой, кайт, DoT).
- **Жесткий контр без метки.**
- **Каша на экране** в 3D-виде сверху.
- **Все стаи одинаковы.**
- **Копия чужого**: облик и набор умений монстров Diablo.

## 2. Решения владельца

- **[Владелец]** Первые враги: **Баал** (босс), **Рыцарь ада** (вожак группы), **козлолюди** (рядовые) по мотивам Diablo. Набросок владелец принял («пока норм»).
- **[Владелец, башня 6.2]** Статы монстров резко прыгают на переходе рангов, появляются новые аффиксы.
- **[Владелец, через «Эндгейм»]** Таймера ярости у боссов нет.
- **[Владелец, через «Эндгейм»]** Пул боссов копится: боссы прошлых рангов приходят на высокие ранги усиленными, в том числе как редкий монстр на обычном этаже.
- **[Владелец, через «Эндгейм»]** Отражения урона и полного иммунитета нет.
- **[Владелец, через «Эндгейм»]** Зелье только здоровья, заряды восстанавливаются на старте этажа.
- **[Владелец]** Визуал — 3D в духе Diablo 2, вид сверху под углом.

**[Решение Claude]** **Права.** Баал — демон из мифологии, имя свободно. Облик, арена и **набор умений** Баала из Diablo 2 (ледяная волна, щупальца из земли, двойник) не используются: в первой ревизии они случайно совпали, арт-ревью это нашло, набор заменен своим (11.3). Козлолюди и рыцарь ада — общие образы жанра, облик свой.

## 3. Понятия

| Понятие | Что это |
|---|---|
| **Вид монстра** | Запись в данных: «Рогач-рубака». Роль, статы, атаки, поведение. |
| **Роль** | Что монстр делает в стае (раздел 5). |
| **Стая** | Группа монстров одного семейства с составом по ролям. |
| **Семейство** | Набор видов с общим образом и правилом стаи: Рогачи. |
| **Чемпион** | Пачка из 2–3 монстров одного вида с общим аффиксом. |
| **Редкий вожак** | Уникальный монстр с именем, аффиксами по рангу и свитой. |
| **Вожак семейства** | Вид, который водит стаю семейства: Рыцарь ада. |
| **Босс / убер-босс** | Отдельный бой с фазами; убер — на вершине по контракту башни 5.2. |
| **Аффикс монстра** | Свойство элиты, меняющее поведение. Тот же каталог берут моды башни (9.1). |
| **Телеграф** | Видимое предупреждение атаки: знак опасности на земле (7.2), замах, звук. |
| **Эталон ранга N** | Эталонные билды на нижней границе уровней ранга (ранги 1–5) или на 60-м уровне с эталонной экипировкой ранга (ранги 6–15, лут 12.2). |
| **Эталонное eHP** | Эффективное здоровье эталона ранга против типа урона (ядро 11.3). |

## 4. Модель монстра в данных

**[Решение Claude]** Монстр расширяет манекен ядра (11.1).

```
MonsterDef {
  id, name, family, role                      // раздел 5
  tags: [demon, beast, ...]
  life: number                                // в единицах «рубака = 1.0»
  armor: number                               // доля брони эталона ранга (1.0 = норма)
  resists: { fire, cold, lightning, poison, dark }  // смещение вида, 6.2
  moveSpeed: number                           // доля базовой скорости героя, кап 7.4
  attacks: AttackDef[]
  behavior: id + params                       // архетип, 4.2
  onDeath: Effect[] | null                    // правила стаи и аффиксов
  freezeDurationMultiplier                    // 6.4
}
AttackDef {
  id, shape: melee | cone | line | circle | projectile | ring
  damage: { type: share }
  power: number                               // урон в единицах «удар рубаки = 1.0»
  telegraphBase: seconds | null               // null = без телеграфа, правило 7.1
  range, radius, cooldown, knockback?
}
```

- **Действующий телеграф** = `max(telegraphBase, минимум_ранга)` (7.1). Поэтому один и тот же монстр на ранге 1 дает больше времени, чем на ранге 10.
- **Баффы стай и аффиксов** выражаются через модификаторы ядра: Increased или More к статам монстра (`damage`, `armor`, `move_speed`, «урон, получаемый целью» с отрицательным знаком). Особых множителей нет.

### 4.1 Масштабирование
- **Здоровье** = `life × базовое_здоровье × M(уровень зоны) × S(ранг)`.
- **Урон удара** = `power × базовый_урон × M(уровень зоны) × S(ранг)`.
- **Броня** = `armor × броня_эталона(ранг)`; **сопротивления** — 6.2.
- **[Решение Claude]** `M` действует **только на монстров башни**. Пресеты манекенов песочницы (`dummies.json`) остаются на силе оружия P = G (лут 4.3), поэтому эталонные билды и `BuildOptimizer suite` не сдвигаются этим документом.

### 4.2 Поведение
Архетип из короткого списка, параметры в данных. Новый архетип — код.
- `chaser` — бежит к игроку, ближний бой.
- `kiter` — держит дистанцию, стреляет, отходит при сближении. Скорость отхода — не выше **0,9 скорости героя**, между отходами пауза (в данных), чтобы бойцы ближнего боя (Палач) догоняли его и били (требование Отступника 8.3).
- `caster_support` — за стаей, баффает своих, иногда атакует.
- `bomber` — бросает снаряды по дуге в точку.
- `pusher` — отбрасывание, лужи, сбивание шкалы (Удержание).
- `hunter` — идет к союзнику игрока (Сопровождение), цель видна.
- `boss_script` — сценарий фаз (раздел 10).

ИИ и навигацию сейчас **никто не делает**: учебная комната по своему документу монстров не водит (манекен не бьет и не ходит). Это отдельная задача после комнаты, в roadmap (раздел 14).

## 5. Роли и стаи

### 5.1 Роли

| Роль | Что делает | Ответ игрока |
|---|---|---|
| **Рубака** | ближний бой, догоняет | зона, отход |
| **Стрелок** | снаряды издалека | сблизиться, уклониться |
| **Заклинатель** | бафф, лечение, призыв своих | убить первым |
| **Рой** | много слабых, быстрые | зона, площадь |
| **Бомбардир** | удары по площади в точку | выйти из круга |
| **Вытеснитель** | отбрасывание, лужи, контроль точки | стоять, чистить |
| **Охотник** | идет на союзника | перехватить |
| **Вожак** | аура или правило стаи | убить или развести |

### 5.2 Стая
- Стая: 4–8 монстров одного семейства, состав по ролям из данных семейства.
- С вероятностью из данных этажа стаю водит вожак семейства или редкий вожак.
- У семейства может быть **правило стаи** (`onDeath`, ауры).

### 5.3 Состав по типам этажей
Требование башни 4.7:

| Тип этажа | Решение игрока | Состав |
|---|---|---|
| Зачистка | темп свой, охота | разрозненные стаи 4–8, часто вожак, 1–2 чемпиона и 1 редкий вожак на этаж |
| Волны | держать арену | рой + стрелки + бомбардиры; каждая 3-я волна с вожаком; к концу сужение арены |
| Ритуал | когда активировать | у точки свой состав, виден до активации |
| Удержание | стоять на точке | вытеснители + бомбардиры, мало роя |
| Сопровождение | защищать союзника | охотники с видимой меткой цели + рубаки |
| Забег на время | маршрут | особые монстры с маркером (дают время) + охрана алтарей (чемпионы) |
| Боссы | бой с боссом | без стай, кроме призывов босса |

### 5.4 Ростер ранга закрывает роли
**[Решение Claude]** Правило «2 новых вида на ранг» (башня 6.2) уточнено: **ростер каждого ранга 1–5 закрывает все роли, которые нужны типам этажей, открытым на этом ранге**. На ранге 1 (башни 1–3: Зачистка, Волны, Забег, Испытание, Боссы) нужны рубака, стрелок, рой, бомбардир, заклинатель, вожак и особый монстр Забега. Рогачи закрывают рубаку, заклинателя-бомбардира и вожака. **Второе семейство ранга 1** (рой и стрелки, например мелкие бесы и лучники-скелеты) — **условие запуска этажа «Волны»**: без него Волны ранга 1 — те же Рогачи, что на Зачистке. Особые монстры Забега — условие Забега на время (башня 2).

## 6. Защита и справедливость классов

### 6.1 Типы урона
Шесть типов: физический, огонь, холод, молния, яд, **тьма**. Тьма не стихия. **Порядок работ:** сначала `DamageType.Dark` в ядре (документ Отступника), потом монстры с сопротивлением тьме.

### 6.2 Сопротивления и броня по рангам
**[Решение Claude]**:

| Ранг | Базовое сопротивление | Смещение вида | Броня вида |
|---|---|---|---|
| 1–2 | 0% | **нет** | ×1,0 у всех |
| 3–5 | 10% | ±10 | ×0,75–1,5 |
| 6–9 | 20% | ±15 | ×0,75–1,5 |
| 10–15 | 30% | ±20 | ×0,75–1,5 |

- **Ранги 1–2 без смещений**: все монстры равны против всех типов урона. Первые скиллы классов (Огненный шар Чародея и т.д.) не стартуют в худших условиях. Разнообразие защит начинается с ранга 3.
- **Правило ростера.** Броня переводится в эквивалент сопротивления (доля снижения физического удара эталона ранга по формуле ядра 5.4). На каждом ранге **среднее по ростеру, с весом «доля спавна × здоровье», одинаково по всем 6 типам (±5 п.п.)**. Это **тест сьюта**, а не загрузчик: этажей в данных пока нет. До башни веса видов и эталонный удар для перевода брони лежат в `difficulty.json` как временные значения. На рангах 1–2 `броня_эталона` подбирается так, чтобы ее эквивалент был не больше 5% (иначе физике достается своя защита при нулевых сопротивлениях).
- Боссы: базовое + 10 п.п., без смещения по типу.
- Аффиксы и моды поднимают сопротивление не выше **75%**, оно всегда пробивается пробитием.
- Сопротивления физике (кроме брони) нет. «Каменная кожа» дает только броню, и с ранга 3.

### 6.3 Нет жестких контров
- Аффиксы ранга никогда не жесткий контр (башня 6.2). Иммунитета и отражения нет.
- **Моно-тип урона** (Палач с «Тёмной кровью» — чистая тьма, Аватар пламени — огонь, Криомант — холод) не должен упираться ни в один аффикс ранга. Поэтому «Щит» (9.2) ломается любым уроном.
- «Нет регенерации», «нет лечения», «нет вампиризма» — только моды башни с меткой «жесткий контр». «Нет лечения» — жесткий контр Отступника («Новый класс»).

### 6.4 Недуги на монстрах и от монстров
**[Решение Claude]**:
- **Множитель длительности заморозки:** рядовые 1,0, чемпионы 0,75, редкий вожак 0,5, боссы 0,5 (как пресет «Босс»). Иммунитет 3 с после заморозки (ядро 6.7) у всех.
- **Заморозка ставит телеграф на паузу**: атака не отменяется, но и не срабатывает, пока монстр заморожен.
- Боссы не замораживаются во время смены фазы и в своем окне оглушения (окно и так их).
- **Монстры накладывают на игрока только охлаждение** (замедление) и урон по времени. Потери управления (оглушение, заморозка игрока) без телеграфа нет; отбрасывание — только с телеграфом.

## 7. Читаемость и справедливость урона

### 7.1 Телеграфы, всплеск и досягаемость
- **Одиночный удар без телеграфа** — не больше **≈35% eHP эталона ранга** против своего типа урона (строже ≈40% башни 6.2, чтобы Палач на 40% здоровья не умирал от удара без телеграфа), с учетом всех множителей: чемпион, редкий вожак, баффы стаи (клич, ярость) и мод урона максимального тира ранга.
- **Всплеск стаи без телеграфа** **[Решение Claude]**: суммарный урон без телеграфа, который стая вместе с элитами может нанести за 1 с, — не больше **≈35% eHP эталона ранга** (те же множители). Иначе пять «честных» рубак дают ваншот.
- Крупный урон — только с телеграфом. **Минимум действующего телеграфа:** ранги 1–2 — **1,5 с**, 3–5 — 1,0 с, 6–15 — 0,7 с. Одна формула: `действующий = max(telegraphBase × множитель_модов, минимум_ранга)`, где множитель модов башни «быстрее» ≥ 0,7. Скорость атаки (аффикс «Быстрый», клич) телеграф **не** укорачивает: она ускоряет только удары без телеграфа и перезарядки. Так минимум ранга — жесткий пол, и 0,5 с не бывает нигде.
- **Досягаемость:** враги не атакуют из-за экрана, кроме видимых снарядов. Отбрасывание не выталкивает за край арены и не в лужу. Отбрасывание Тарана Рыцаря ада и вытеснителей (`pusher`) на Удержании проверяется вживую на Палаче: ему нужна дистанция удара для ресурса и лечения.
- Обе проверки eHP — **тест сьюта**, а не загрузчик (13.2): им нужны скомпилированные эталоны ранга.
- **Ограничение симуляции.** Ядро не различает ближний и дальний бой: в нем удар без телеграфа получают все. Для Палача, который по дизайну живет на 40–70% здоровья, это правило проверяется отдельно (тест 13.4.2), а честность для кайта и ближнего боя вживую — только в живом бою.

### 7.2 Язык телеграфов (требование к арту)
**[Решение Claude, по арт-ревью]**:
- **Знак опасности**, которого нет у эффектов героя: яркий контур формы атаки и заполнение **от края к центру**, полное — удар. Контур одного закрепленного цвета (подбирает арт-директор), который **не используют** ни эффекты скиллов героя, ни маркеры элит (синий чемпиона, золотой вожака).
- **Тип урона** передается только оттенком заливки: физ — белый/серый, огонь — оранжевый, холод — голубой, молния — желтый, яд — зеленый, **тьма — темное ядро и светлый фиолетовый край** (правило учебной комнаты, иначе тьма теряется на темном полу). Красного цвета урона нет.
- **Лужи** (лед, яд, огонь от модов) — текстура поверхности без контура и без заполнения: «здесь плохо стоять», а не «сейчас ударит».
- **Тьма у врагов** — только атаки через знак опасности. Луж тьмы у врагов нет. Зоны тьмы героя (Отступник) — искры и тлеющие угли без трещин (трещины — у «Трещины» Баала), бледнее телеграфа и ниже его по слою.
- **Порядок слоев:** телеграф > лужа > эффекты героя > декор. В плотном бою эффекты героя приглушаются. Лимит видимых луж на экране — в данных, моды «на всех» дают лужи мельче и тусклее.
- **Элиты:** чемпион — насыщенный синий **контур** (не заливка, чтобы не путать с холодом), синее имя; редкий вожак — золотой контур, метка на земле под ним, золотое имя и аффиксы под полоской здоровья.
- **Силуэты** с камеры сверху различаются по **ширине, предмету в руке и собственному свечению**, а не по росту.
- Ауры и радиусы — не шире ~6 м (кадр ≈10–11 м); усиленные аурой монстры помечаются сами.

### 7.3 Скорость монстров
**[Решение Claude]** Скорость движения монстра со всеми баффами — **не больше 110% базовой скорости героя**. Рывки и прыжки с телеграфом — вне капа. Иначе «быстрый» рубака под яростью и аурой скорости ломает кайт.

## 10. Боссы

### 10.1 Контракт этажного босса
- 1–2 фазы, 3–5 атак, хотя бы одна с телеграфом и крупным уроном.
- **Окно урона в каждой фазе** раз в 30–45 с.
- Время убийства средним эталоном ранга: 45–90 с на голом ранге. Таймера ярости нет.
- Призывы — только отдельной атакой с телеграфом, не постоянным потоком.

### 10.2 Убер-босс
Контракт башни 5.2: **≥2 фазы**, **≥1 механика только у убер-версии**, явное окно урона. Здоровье ×2 от этажного, урон ×1,25. Проходим эталоном нижней границы ранга.

**Исключение — учебные убер-боссы** башен 1–2 ранга 1 (башня 6.5): одна читаемая механика, телеграф ≥ 1,5 с, ответ «отойти». У них флаг `tutorial` в данных, и валидатор не требует от них фаз и механики «только убер».

### 10.3 Пул боссов
- На рангах 1–5 — 2 новых босса на ранг, пул ранга ≥ 6. На рангах 1–2 пул добирается учебными боссами и боссами-вожаками (увеличенный вожак семейства с одной механикой).
- **[Владелец]** Пул копится: босс ранга N приходит выше со статами текущего ранга и **+1 аффиксом** за каждые 3 ранга сверху. Как редкий монстр на обычном этаже — этажная версия без последней фазы, здоровье ×0,4.
- **Белый список аффиксов для боссов:** только «Быстрый», «Огненное зачарование» (без взрыва после смерти), «Каменная кожа», «Щит», «Ядовитое облако», «Метка гибели», «Буря». «Призыватель», «Вторая жизнь», «Телепорт», «Оковы», «Кровопийца» ломают фазы и не выдаются боссам.

### 10.4 Босс в конце этажа
Башня 4.6: этажная версия из пула ранга, без призывов, если этаж уже про стаи.

### 11.1 Рогачи (семейство, рядовые)
Образ: козлоногие демоны-дикари, шкуры и кости, широкие рога. Факелы — светящийся материал без источника света. Тег `demon`. Ранг ввода: 1.

### 11.2 Рыцарь ада (вожак Рогачей)
Образ **[по арт-ревью]**: демон в черных шипастых латах, широкий корпус, рога и шипы на плечах, **двуручная булава**, без щита. Силуэт не повторяет героя-паладина с мечом и щитом. Тег `demon`. Ранг ввода: 1 (без ауры), полный набор с ранга 2.

- Здоровье 6,0, скорость 0,8, броня ×1,0 (ранги 1–2), ×1,5 с ранга 3 (с поправкой ростера).
- **Сокрушающий удар** 3,0 — конус 120°, 4 м, `telegraphBase` 1,0 с.
- **Таран плечом** 2,5 — линия 8 м, `telegraphBase` 0,8 с, отбрасывание 3 м.
- **Аура «Железный строй»** (с ранга 2): рогачи в 6 м получают **−15% получаемого урона** (нейтрально к типу урона, а не броня, чтобы не бить только по физике). Усиленные рогачи помечены знаком на земле.
- **Оцепенение:** когда рыцарь гибнет, аура пропадает, и рогачи его стаи **3 с стоят на месте** (не атакуют, не бегут). Окно для зоны и для ближнего боя.
- Может быть редким вожаком.

### 11.3 Баал (босс) — набор умений свой
Образ: древний демон-разрушитель, высокий, в истлевших доспехах-ризах, с огромным скипетром-кистенем; трещины тьмы светятся сквозь тело. Тело гуманоидное (ассеты, 14). Тег `demon`. Этажный Баал — в пуле с ранга 4, убер-Баал — вершина ранга 5 (финал прокачки), потом возвращается по 10.3.

**Этажная версия**, здоровье 60, 2 фазы:
- **Обвал** 3,0 (физ.) — 3 круга 2,5 м: один под игроком, два случайно в 4–8 м от него; `telegraphBase` 1,5 с. Раз в 8 с.
- **Трещина** 2,5 (тьма) — трещина по линии от Баала к игроку, 2 м шириной, `telegraphBase` 1,0 с, потом извергается.
- **Удар скипетром** 1,5 (физ.) — ближний бой без телеграфа (правило 7.1).
- **Окно фазы 1:** после третьего Обвала Баал 4 с «вбирает разрушение» (стоит, светится) и получает +25% урона.
- **Фаза 2 (≤50%): Опоры.** Баал ставит на арене 3 обелиска-опоры (здоровье 8% от Баала каждая, видны и подсвечены). Пока стоит хоть одна, Баал получает −50% урона, а Трещина идет двумя линиями. **Окно:** разрушение последней опоры оглушает Баала на 4 с. Новые опоры — через 30 с после окна. Опоры не атакуют; эффекты «при попадании» (например, лечение «Жатвы» Палача) по ним работают, но их всего 3 и они разрушаются, поэтому бесконечного возврата нет.

**Убер-версия**, здоровье 120, 3 фазы:
- Все из этажной.
- **Фаза 3 (≤25%): Рушащаяся башня** — механики нет у этажной версии. Пол арены разбит на плиты; каждые 6 с одна треть плит подсвечивается знаком опасности (2,0 с) и обрушивается в пустоту (урон по времени тьмой 0,5/с, пока стоишь на месте провала, плиты возвращаются через 8 с). Одновременно может отсутствовать не больше 1/2 пола; новая треть выбирается так, чтобы от любой точки до целой плиты было ≤ 2,0 с ходьбы, и никогда не отрезает игрока без выхода. У провала светлый фиолетовый край и свет снизу, чтобы он не сливался с тьмой. **Плита рядом с Баалом не обрушивается никогда**, поэтому ближний бой всегда может стоять у него. Окно: после каждого обрушения Баал 2,5 с восстанавливает опору (+25% получаемого урона).
- Если на пороге 25% опоры фазы 2 живы, они исчезают, и Баал оглушен на 2 с.
- Сопротивления: базовое ранга + 10, без смещения. Белый список аффиксов 10.3 для возвращения на высоких рангах.

### 13.2 Валидатор (загрузчик, строгий)

### 13.3 Симуляция: этапы
Ядро не моделирует пространство, а защита и атака сейчас общие на весь пак манекенов (`DummyDefinition`, `UseResolver.DefenseOf`).

**Этап 1 (малое изменение ядра).** **[Решение Claude]** Сейчас `SimRun` умножает жизнь и урон манекена на `Growth.Gear` (G). Этап 1 добавляет в `DummyDefinition`/`SimRun`:
- **множитель силы врага** вместо жесткого G: по умолчанию G (= P, лут 4.3), для монстров башни `M × S` — эталоны и `BuildOptimizer suite` не сдвигаются (тест: `suite` до и после совпадает);
- **постоянный «получаемый урон» пака** (для окон босса и ауры «−15% получаемого урона»). По правилу ядра 6.6 он **суммируется в ту же Increased-корзину «урон, получаемый целью»**, что и шок (`DamageTakenIncreased`), а не отдельным More; в разборе — своей строкой внутри корзины;
- **строку разбора** «уклонено телеграфов: X%» в Explain.
- У монстров нет своего вычислителя статов, поэтому на этапе 1 баффы стай (клич, ярость, аура) для тестов 13.4.2 и 13.4.5 считаются в коде теста как худший случай, а не модификаторами; модификаторы монстров — этап 2.
- Стая = **однородный пак «среднего монстра»**: здоровье, броня и сопротивления — средние по составу с весом здоровья; размер пака = размер стаи.
- Атака стаи = одна атака пака: средний урон в секунду ролей с учетом **доли уклоненного телеграфного урона** (параметр в данных, стартово 80%), сведенный к одному удару и интервалу.
- Босс = манекен с конечным здоровьем и усредненным потоком атак по фазам; окна урона — +X% получаемого урона на долю времени.
- **Не моделируются** (проверяются только вживую): правила стай (ярость, оцепенение, аура, клич), аффиксы поведения (призыв, телепорт, щит, кровопийца, вторая жизнь, лужи), опоры и плиты Баала. Чемпионы и вожаки — только множители здоровья и урона.

**Этап 2 (изменение ядра, вместе с живым боем).** Смешанные паки: здоровье, защита и атака у каждой цели (`SimState`, `TargetState`, `UseResolver`, `DamageLedger`, Explain), `onDeath` монстр → монстр, фазы босса.

### 13.4 Тесты (режим «среднее», этап 1)
1. **Справедливость классов:** эталоны Воителя, Чародея, Отступника убивают средние стаи ростера каждого ранга за время в пределах ±25% от среднего по классам **и** выживают против атаки стаи не меньше заданного времени.
2. **Всплеск для низкого здоровья:** эталон Палача на 40% здоровья переживает худший удар без телеграфа и худший всплеск стаи ранга (7.1).
3. **Стена ранга:** 8.2.
4. **Босс:** этажный 45–90 с, убер проходим эталоном нижней границы ранга.
5. **Ваншот и всплеск:** обе проверки 7.1 на всех рангах, со всеми множителями.

## 14. Требования к другим сессиям
- **Управление проектом:** ИИ и навигация монстров никем не делаются; нужна задача после учебной комнаты (4.2).
- **Ядро («Система диаблоида»):** `DamageType.Dark` раньше монстров с тьмой (6.1); этап 2 симуляции (13.3).
- **Новый класс (Отступник):** `DamageType.Dark = 5` в конце перечисления и `resist_dark` у врагов. Опоры Баала и другие неподвижные цели, которые можно бить, — обычные цели для печатей. Пересборку эталонов (`rebuild_references.ps1`) две сессии не запускают одновременно: порядок согласуется перед кодом — сначала Отступник, потом план 6.
- **Арт:** язык телеграфов, слои, маркеры элит и силуэты 7.2; три образа 11. **[Решение владельца 2026-10-30]** Модели Рогачей и Баала пробуем **генерировать в пайплайне** (например, Meshy, скелет и анимации через Mixamo), не покупаем и не заказываем. Рыцарь ада — `Warrok W Kurniawan` с новыми латами; бесы, скелеты и массовка — бесплатные модели Mixamo и Sketchfab CC-BY (подборка арта).
- **Эндгейм:** каталог аффиксов и запрещенные пары 9.2 для поведенческих модов; состав по типам 5.3; пул боссов 10.3; второе семейство ранга 1 нужно уже к первым башням (5.4).
- **Лут:** выпадение по ролям 12.
