# Три курсора для игрового тестирования

По поручению владельца добавлены три выбранных растровых варианта: витраж (`glass`), готический наконечник (`spear`), башенный ключ (`key`). Первый запуск — витраж. F8 циклически переключает варианты, выбранный ID сохраняется между запусками в отдельном `user://cursor.cfg`. Во время ввода текста, открытого popup и при модификаторах/повторе клавиши переключение не выполняется. Короткая подпись показывает выбранное имя.

Одна выбранная форма применяется к Arrow и PointingHand; отвергнутые меч и латная рука больше не активны. Системные IBeam/Resize и управление видимостью курсора геймпадом сохраняются.

Происхождение: оригиналы Venice, референс и промпты — `../2026-11-03-venice-358/`; прозрачные производные GPT — там же в `cutouts/` с отдельным provenance. Новых генераций на этапе подключения нет. Экспорт — `export.ps1`, только прозрачное центрирование/масштабирование до48×48, без цветовой обработки. Точный manifest и hotspot — `runtime-manifest.json`.

Точки клика на непрозрачном рабочем конце: витраж (2,2), наконечник (6,3), ключ (2,2). Основные ресурсы лежат в `game/Ui/Art/Cursors/{glass,spear,key}.png`, доступны в экспорте игры без внешних путей.

Это игровая проба трёх форм, а не утверждение выбранного владельцем единственного финального курсора. Ранее отмеченные особенности cutout (яркость витража, мелкая светлая кайма) нужно оценивать в движущейся сцене; ключ может быть менее заметен на тёмном фоне.

Проверено: сборка без ошибок, с тремя предупреждениями NU1900 из-за недоступности NuGet audit; импорт, headless и GPU завершились с кодом0. CURSOR_OK подтверждает три48pxPNG и точки клика; CURSOR_SELECTION_OK — выбор, цикл, сохранение, загрузку, повреждённые настройки и защиту ввода; CURSOR_BUTTONS_OK — кнопочные формы; CURSOR_F8_OK — настоящий маршрут Viewport.PushInput, сохранение только временного тестового cfg, игнорирование повтора и исчезновение подписи. Настройки реального профиля тестами не меняются. При намеренно битом cfg ожидается parse error; в sandbox известно сообщение о root certificate store. Независимое UI-ревью: APPROVE. Игровые кадры: in-game-glass.png, in-game-spear.png, in-game-key.png. Native cursor не попадает в viewport capture, поэтому кадр содержит отдельные TextureRect48px и увеличение3x на контрастных плашках.

Владелец отдельно отметил витраж как понравившийся материал: см. `docs/art/STAINED_GLASS_EXPLORATION.md` и дополнение к ART_DIRECTION.md.
