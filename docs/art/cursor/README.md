# Курсор башенного мира

Оригинальная векторная геометрия, без генеративной фактуры: графитовая сталь, холодная светлая кромка и сдержанный красный акцент. Арт-направление — `docs/art/ART_DIRECTION.md`, утверждённый Venice D4. Это служебный знак, а не отдельное исследование нового визуального стиля.

Ресурс: `game/Ui/Art/Cursors/tower-pointer.svg`, прозрачный холст 40×40, hotspot (3,3) совпадает с остриём. Тёмная внешняя линия нужна на светлом фоне; светлая кромка — на тёмном. Без glow, шума и встроенного фона. Arrow и PointingHand используют этот указатель; текстовые и системные resize-формы не заменяются.

Курсор включается отдельным autoload TowerCursor. Native hardware cursor не попадает в обычный скриншот viewport, поэтому проверочная сцена дополнительно показывает тот же ресурс настоящего размера на контрастных плашках поверх реальной игры. Эти плашки не входят в обычный интерфейс.

Проверено: сборка 0 ошибок и предупреждений, импорт exit 0, TowerCursorCheck в headless и на GPU exit 0. CURSOR_OK подтверждает размер, непрозрачность hotspot и native=True при графическом запуске. Независимый UI-куратор: APPROVE. На геймпадное скрытие указателя и MouseMode autoload не влияет. Кадр: `in-game.png`; точный экспорт: `tower-pointer.png`.
