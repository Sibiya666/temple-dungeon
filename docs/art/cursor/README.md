# Курсор башенного мира

Оригинальная векторная геометрия, без генеративной фактуры: графитовая сталь, холодная светлая кромка и сдержанный красный акцент. Арт-направление — `docs/art/ART_DIRECTION.md`, утверждённый Venice D4. Это служебный знак, а не отдельное исследование нового визуального стиля.

Текущие ресурсы: `game/Ui/Art/Cursors/tower-sword.svg` для Arrow, hotspot (3,3) на острие, и `tower-hand.svg` для PointingHand, hotspot (12,3) на указательном пальце. Оба — прозрачный холст 40×40. Тёмная внешняя линия нужна на светлом фоне; светлая кромка — на тёмном. Без glow, шума и встроенного фона. Текстовые и системные resize-формы не заменяются. Первоначальный `tower-pointer.svg` сохранён как неиспользуемая история.

Обычные BaseButton с исходным Arrow получают PointingHand, в том числе добавленные динамически. При наведении учитывается Disabled. Явные специальные формы контролов сохраняются. Если Disabled меняется под неподвижным указателем, форма обновится при повторном наведении. Подписки очищаются при удалении кнопок и выходе autoload. CURSOR_BUTTONS_OK проверяет обычную/disabled/re-enabled кнопку, явные IBeam/Cross и неинтерактивный Control.

Курсор включается отдельным autoload TowerCursor. Native hardware cursor не попадает в обычный скриншот viewport, поэтому проверочная сцена дополнительно показывает тот же ресурс настоящего размера на контрастных плашках поверх реальной игры. Эти плашки не входят в обычный интерфейс.

Проверено: сборка 0 ошибок и предупреждений, импорт exit 0, TowerCursorCheck в headless и на GPU exit 0. CURSOR_OK подтверждает размер, непрозрачность двух hotspot, различие ресурсов и native=True при графическом запуске. Независимый UI-куратор: APPROVE для обеих форм. На геймпадное скрытие указателя и MouseMode autoload не влияет. Кадр: `in-game-forms.png`; точные экспорты: `tower-sword.png`, `tower-hand.png`. Первоначальные кадры оставлены как история.
