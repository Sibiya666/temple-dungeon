# Dialoid — локальная HTML-презентация дизайн-системы

Самодостаточный `index.html`: CSS, JavaScript и все изображения встроены. Открывается напрямую в браузере через `file://`, без сервера, сети, CDN, установки пакетов или публикации.

## Замысел

Главный объект — реальные визуальные материалы Dialoid, главное действие — последовательно рассмотреть систему и открыть нужный кадр крупнее. Направление уже выбрано владельцем: уголь, холодный металл, ivory и витраж. Презентация использует крупную редакционную типографику, непрерывные полосы изображений и архитектурную обложку вместо сетки одинаковых карточек.

Семь секций: обложка; основы; витраж и состояния; первый общий лист; навыки; Башня; применение. Первый лист явно обозначен как презентационный монтаж, игровые окна — как локальные реализации с арт/UI-ревью. Художественный HUD не объявлен финализированным. Готовность комплекта иконок всех узлов, коммит и принятие в main не утверждаются.

## Сборка

```powershell
& ./build.ps1
```

Параметры `-MainRoot` и `-WorktreeRoot` позволяют указать расположение исходных копий. Скрипт хранит весь HTML-шаблон и заменяет именованные placeholders на PNG dataURI. Запускается стандартным PowerShell без зависимостей. Исходные внешние пути нужны только сборке, готовый HTML от них не зависит. Всего 12 исходных изображений; несколько отображений одной иконки встроены повторно.

## Взаимодействия и доступность

- Якорная навигация и индикатор текущего раздела (`aria-current`). Клавиши вправо/влево переходят между секциями; перехват отключён в inputs, buttons, select, textarea, contenteditable, при модификаторах и открытом dialog.
- Увеличение кадров: `button[data-zoom]` → native `dialog`, название/описание, кнопка закрытия, Escape, возврат фокуса на исходную кнопку. Нажатие вне dialog также закрывает просмотр.
- `button[data-print]` вызывает системную печать. PrintCSS убирает навигацию и интерфейсные накладки, переводит текст на светлый фон, разделяет главы. PDF не создаётся автоматически.
- HTML-образцы показывают раздельные иллюстрацию, выбор и фокус; нажатие меняет `aria-pressed` и сообщение `aria-live`, не игровые данные.
- Mobile: упрощённая числовая навигация, одна колонка деталей, перенос палитры и иконок.
- `prefers-reduced-motion` отключает smooth scroll, переходы и анимации. Без этого — короткие hover-переходы, появление визуальных полос при прокрутке и мягкая глубина архитектуры на широком экране. Использованы нативные CSS scroll timelines вместо внешней библиотеки, чтобы сохранить полную автономность и отсутствие новых зависимостей; в старом браузере страница остаётся читаемой без привязки анимации к прокрутке.
