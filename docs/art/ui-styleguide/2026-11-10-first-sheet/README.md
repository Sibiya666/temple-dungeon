Статус: предложение для визуальной приёмки, не внедрено в runtime.

## Философия: холодный переплёт

Башня проявляется через вертикаль и расстояние между освещёнными плоскостями. Тщательно выверенные поля дают архитектуре оставаться на периферии, сохраняя спокойную область для действий игрока.

Материал объединяет элементы: тёмный металлический переплёт держит стекло, холодная грань различает контур. Точность исполнения выражается в постоянстве толщины, геометрии и выравнивания, а не в общем декоративном шуме.

Свет принадлежит форме. Серебро и слоновая кость несут информацию, смысловые оттенки остаются внутри стекла. Каждая подсветка требует столь же внимательной настройки, как её отсутствие.

Размер подчинён задаче: крупная форма читается раньше мелкой детали. Подписи коротки, числа достоверны, композиция оставляет пространство для восприятия.
