## Происхождение

Все семь изображений архитектуры повторно используют существующие мастера `docs/art/icons/2026-10-31-venice-full-backgrounds/<id>.png`; модель/промпты/метаданные/исследовательский статус сохранены рядом с оригиналами. Задники не перегенерировались. Для исправления Ascendancy выполнено 7 встроенных GPT imagegen вызовов — по одному на собственную иконку узла, каждый от одного утверждённого Venice-оригинала. Платные CLI/API и покупки не использовались; денежная стоимость встроенным инструментом не сообщена. Новый лицензирующий вывод не делается. Визуальные элементы раскладки — собственный воспроизводимый System.Drawing-скрипт; системные Segoe UI / Georgia используются для локального макета и не распространяются как font-файлы.

## Проверка и ограничения

Запуск: `powershell -NoProfile -ExecutionPolicy Bypass -File ./build-variants.ps1` из этой папки. Все семь основных PNG — 1600×900, общий лист — 2400×2900. Автор открыл и просмотрел каждый основной PNG. Данные иллюстрируют имеющиеся поля/команды, но не являются результатом симуляции или воспроизводимым боевым логом.

Новых навыков/узлов нет. Существующие 7 узлов Берсерка получили собственные смысловые иконки в icons/originals/, промпты в icons/prompts/, точный референс в icons/reference/, происхождение в icons/provenance.json. Механические экспорты64/32/24 находятся в icons/export/, размерный лист — icons/size-check.png. Граф соответствует AscendancyPanel.Layout/Links: старт в центре, 6 независимых прямых связей к notable по кругу в порядке данных; рёбра прерваны под подписями. Выбор — только blood_feast, фокус отдельными уголками; взятые узлы обозначены подписью. Иконка blood_feast повторяется в detail. Комплект подключён к статическому макету по точным ID; runtime-подключение и игровой кадр остаются невыполненными. Числа, доступность и состояния в макетах не подтверждают runtime-поведение. Прокрутка, геймпад, 1280×720, настоящая игровая камера/HUD, применение RoomHudTheme и порт в Godot требуют отдельной реализации и проверки. Общий лист и макеты не заменяют такую приёмку.

Выбор режима измерителя сохраняет четыре существующие опции: DPS по скиллам, урон по скиллам, урон по типам, потери на защите.
