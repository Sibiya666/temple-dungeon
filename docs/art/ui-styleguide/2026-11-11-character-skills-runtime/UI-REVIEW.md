## Блокеры

1. **Skills — числовые значения скрыты многоточием.** `after/charskills-720-skills-detail-bottom.png`: длинные NumberLabel с повтором «Рассекающий удар —» обрезаются до значений; например среднее попадание/прирост ресурса/шанс недуга. Это наблюдается также в900detail-bottom/expanded. Игрок не может сравнить итоговые величины без открытия каждой подсказки. Укоротить локальную подпись, перенести строки либо выделить всегда видимую числовую часть; сохранить исходный NumberLine/context/callback разбора.
2. **Character — обрезано значение бонуса основного атрибута.** На720и900 `character-side-bottom` последняя строка заканчивается многоточием до итогового значения. Число должно оставаться видимым в исходной боковой ширине. Исправление локальное, без изменения общего NumberLabel для остальных принятых окон.
3. **Skills720 gamepad — нижние badges обрезаны границей графа.** `after/charskills-720-skills-pad.png`: нижние два узла упираются в y647; нижние части0/1 скрыты. Fit должен учитывать badge/focus и реальную высоту после появления footer. При этом вложение очка, undo и возврат фокуса не должны сбрасывать ручные pan/zoom.

Блокеры переданы root и профильным авторам. Требуется повторная сборка и GPU кадров затронутых состояний.
