# Character and Skills — Tower05 runtime

Реализованы живые окна персонажа и навыков: узкое/развёрнутое представление, общая тема Башни, утверждённые Venice-задники. Character сохраняет настройки, снаряжение, нарушения билда и разбор чисел. Skills сохраняет каталог, назначения, уровни, очки, undo, дерево и управление мышью/геймпадом. Направления на геймпаде перемещают фокус; A выбирает узел.

Beads: dialoid-vec; локальные этапы dialoid-5u9 и dialoid-eo6. Новых навыков/узлов/Core/data нет. Индивидуальные иконки прочих существующих деревьев остаются отдельным известным долгом; эта работа не объявляет их готовыми.
