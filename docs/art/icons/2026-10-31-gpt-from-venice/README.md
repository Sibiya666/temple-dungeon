# GPT: предложения по эталонам Venice

По запросу владельца встроенному GPT imagegen переданы визуальные референсы утверждённого D4-концепта Venice, серии четырёх иконок и трёх задников. Два концепт-листа: `icons.png` и `backgrounds.png`. Это предложения для сравнения, не финальный атлас и не подключённые игровые ресурсы.

Иконки слева направо: рассекающий удар, стальная защита, огонь, ресурс. Задники: персонаж, навыки, пассивки. Принципы — башенный мир, холодный рассеянный свет, мягкие глубокие тени, сдержанные акценты и отсутствие каменной зернистости. Промпты в `prompts.json`. Генератор: встроенный imagegen, без Venice API на этом шаге.
