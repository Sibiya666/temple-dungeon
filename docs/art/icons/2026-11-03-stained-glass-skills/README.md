# Пять витражных вариантов навыков

Запрос владельца: пять иконок в духе понравившегося осколка витража. Пять вариантов существующих навыков одобрены владельцем 2026-11-03 («Супер, оставляем!») и выбраны для runtime-подключения; новые навыки и узлы не создавались.

Пять смысловых мотивов: рассекающий удар (`cleave`), боевой клич (`battle_cry`), огненный шар (`fireball`), ледяное копьё (`ice_lance`), искра (`spark`). Предметы собраны из стекла и объёмных металлических переплётов; рисунок не нанесён поверх общего одинакового осколка.

Референс: `reference/venice-glass.png`, точная копия оригинала `docs/art/cursor/2026-11-03-venice-358/glass.png`. Исходник Venice выбран владельцем; концепт не перегенерируется. Каждая иконка — отдельная предметная замена через встроенный GPT imagegen от этого оригинала, без цепочки правок и без внешнего платного API на этом шаге. Промпты сохранены до генерации в `prompts/`, происхождение в `provenance.json`.

`masters/` — полные оригиналы результатов, `export/` — механическое масштабирование до64/32/24px, `preview.png` — сравнительный лист. `export.ps1` воспроизводит только масштабирование/композицию, не меняет цвет, свет или рисунок.

Выбрана именно эта пятёрка. Проверки подключения и реальные игровые кадры находятся в `adoption/`. `preview.png` сохранён как исторический лист художественных проб до подключения, с прежней подписью.

Авторская проверка: просмотрены все пять мастеров и контактный лист; сверена точная копия референса по SHA256; размеры15экспортов проверены автоматически. На64px все пять мотивов различаются. В24px холодные копьё/молния и меч/рог сохраняют силуэт; внутренний витражный рисунок упрощается естественно при уменьшении. Огненный шар темнее остальных — в24px основной ориентир красно-янтарный круг и силуэт хвоста. В сравнении с оригиналом новые светлые стеклянные плоскости более молочные и выразительные, а цветовое стекло заметнее; не заявлять пиксельного сохранения эталона. Независимый UI-куратор cursor_review: APPROVE для сравнительного показа, не для runtime. Последующая runtime-проверка и итоговое независимое UI-ревью описаны в `adoption/`.
