# Семь оставшихся задников — GPT от оригинала Venice

Асцендант, билды, разбор, симуляция, журнал, измеритель и графики. Все созданы встроенным imagegen, каждый от одного исходного `../2026-10-31-venice-tower-backgrounds/skills.png`, без цепочки перегенераций. Промпты рядом с PNG. Меняется только тематический предмет в верхней виньетке; архитектура, свет и тёмная нижняя область сохраняются.

Это исходные изображения, не подключённые в игру. Для существующих персонажа, навыков и пассивок сохраняются оригиналы Venice. При интеграции подбирать кадрирование под конкретное окно и проверять реальный UI; квадратный мастер не задаёт геометрию окна.
