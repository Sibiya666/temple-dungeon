# Три стилевых примера окна навыков

По запросу владельца: три самостоятельных концепта одного экрана в духе WoW, Diablo IV и Path of Exile. Это оригинальные изображения, созданные встроенным imagegen; игровые ассеты и логотипы не копируются. Концепты не являются скриншотами Dialoid и не подключены в игру.

Общая композиция: окно навыков, верхняя виньетка с мечом/посохом/книгой, четыре иконки навыков слева, выбранный рассекающий удар в центре, пассивки справа. Различаются рисунок, материалы, палитра и декор. Генеративные макеты могут различаться мелкими деталями геометрии и текста.

- `wow.png`: яркая ручная живопись, крупные формы, дерево и латунь.
- `d4.png`: строгая готика, железо, бордовая ткань, приглушённый свет.
- `poe.png`: арканная бронза, филигрань, драгоценные камни и связи талантов.

Точные промпты: `prompts.json`.
