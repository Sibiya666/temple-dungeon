# Venice: три независимых концепта UI

Запрос владельца: использовать первую концептную стадию 3D-пайплайна для интерфейса. Сервис Venice, модель seedream-v5-pro, существующий скрипт `spike-3d/tools/venice.ps1`. Оригинальные исследовательские концепты, не скриншоты игры; в runtime не подключены.

Три независимых композиции: WoW — открытый учебный кодекс; D4 — строгий полноэкранный интерфейс с вертикальным деревом; PoE — радиальная сеть пассивок и панель связанных камней. Промпты в отдельных TXT, параметры и исходный ответ о размытии сохраняются в JSON рядом с PNG. Условия использования унаследованы от исследовательского пайплайна, без нового утверждения о лицензии.
