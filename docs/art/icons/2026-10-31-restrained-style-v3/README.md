# Сдержанная живопись: иконки и задники

Выбор владельца: ближе к PoE и Diablo, спокойнее яркого v2. Проверка на одной иконке и двух тематических фонах; это отдельные пробы, без замены текущих игровых ресурсов.

Принципы: глубокие угольные тени, приглушённые сталь и бронза, локальные цветовые акценты, читаемый силуэт. Убрать равномерную каменную зернистость. На задниках сохранить тематическую виньетку наверху, оставить нижние две трети спокойными под живые элементы интерфейса.

Источники: `assets/icons/2026-10-31-painted-style-v2/masters/cleave.png`, `game/Ui/Art/WindowPanels/character-v1.png`, `game/Ui/Art/WindowPanels/skills-v1.png`. Генерация: встроенный imagegen, style-transfer edit. Исходники сохранены, новые файлы лежат рядом в этой папке.

Проверка ниже выполняется на макете с настоящими размерами иконок и отдельно набранным текстом; макет не является скриншотом работающей игры.
