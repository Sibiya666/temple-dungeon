# Оружие, классы, симуляция и метки элит

2026-10-31. Первая партия по очереди оставшихся пробелов. Реальное подключение к принятой 3D-комнате; правила игры и порядок ID не менялись.

## Подключено

- Оригинальные рисунки Воителя и Чародея, меча, двуручного топора, посоха и жезла. Встроенный image_gen:6 генераций и2 правки. Staff-v2 и wand-v2 выбраны за различимые навершия и силуэты на24px; ранние masters сохранены. [Промпты и происхождение](provenance.md).
- В CharacterPanel селекторы класса и оружия показывают картинки24px. Русские подписи, массивы выбора и исходные обработчики ItemSelected сохранены. «Нет оружия» без картинки; неизвестный ID не подменяется другим предметом/классом.
- В SimulationPanel иконки стоят у DPS и суммарного урона по скиллам и типам, а также у входящего/полученного урона по типам. Это Icon исходного NumberLabel, поэтому кликабельный разбор и значения остались прежними. Тип берётся из реального DamageType строки, не выводится из цвета скилла.
- Журнал симуляции показывает рисунки по структурированным AilmentId/SkillId и сохраняет весь исходный текст через AddText, без BBCode и разбора строк.
- Для чемпионов подключён двойной шеврон, для редких врагов — трёхзубая корона. Оригинальные SVG, размер16px, цвет ранга сохранён; формы различаются без цвета. TargetPlateView использует реальный TargetRank, а при отсутствии текстуры сохраняет прежнюю геометрию. Ранги и враги в игре не выдумываются ради картинки.

Ресурсы внутри res://Ui/Art/Icons; masters — assets/icons/2026-10-31-equipment-simulation/masters. Всего в каталоге75 визуальных файлов; SHA-256 перечислены в runtime-assets.csv. Нет сторонних исходников, emoji, покупок, внешних API или ключей. Изображения не объявляются CC0/эксклюзивными.
