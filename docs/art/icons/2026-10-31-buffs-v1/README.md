## Подключение и смысл

GameIcons.Timed получает TimedEffect из ядра. Недуг ищется по точному AilmentId; бесконечный бафф mechanic:berserk_frenzy нормализуется в известный ID; счётчик static_charge:charges получает рисунок заряда. Другие счётчики сохраняют нейтральный символ механики. Сырые ключи состояния не становятся путями к файлам. EffectChip оставляет исходный полный текст, реальные стаки, таймер и рамку; изображения не меняют данные боя.

Категории остальных баффов сверены с модификаторами data/skills.json. В частности, hardened_body/unyielding — здоровье, ion_shield — уклонение, ancestral_fury — крит, blood_cry/endless_rage — ресурс, shoulder_bash — скорость, afterimage/frost_wake — защита. Фокус перемещения изображает усиление заклинаний, а не шанс крита.

Проверка сначала падала на общей картинке Боевого клича. После подключения BUFF_ICONS_OK проверяет8 отдельных файлов, формат ключей механик, различие недуга и баффа, а также настоящий EffectChip с текстом «Статический заряд: 7». Сборка без ошибок и предупреждений. Код смысловых назначений и обработки состояний получил независимое APPROVE; художественное направление этой v1 партии не утверждено после нового пожелания владельца.

[Кадр живых баффов](live-buffs.png) получен из реального Боевого клича существующего эталона Воителя через ядро, а не нарисованными числами. Счётчики, длительность и список эффектов не выдумывались для сцены. Ресурсы внутри res://; большие оригиналы остаются в assets/icons/2026-10-31-buffs-v1/masters. Встроенный image_gen, без сторонних исходников, API, ключей или покупок.
