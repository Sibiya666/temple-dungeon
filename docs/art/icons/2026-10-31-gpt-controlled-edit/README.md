# GPT: проверка узкого редактирования эталона

Цель владельца — предсказуемое сохранение художественного направления Venice при работе через GPT. Это проверка метода, не обещание детерминированной генерации.

Две пробы: заменить меч на топор в иконке; заменить небольшой меч рядом с кафедрой на посох в заднике. Каждая получает ровно один исходный PNG Venice и отдельный узкий промпт. Никаких стилевых прилагательных, просьб улучшить, усилить свет, читабельность или предложить своё видение.

Рабочий шаблон: «Измени только [объект]. Сохрани композицию, фон, палитру, экспозицию, контраст, мягкость границ, свет и детализацию исходника. Всё вне объекта оставь без изменений. Не добавляй свечение, фактуру, декор и резкость».

Процесс серии: один утверждённый оригинал на семейство; каждый вариант делать от него, а не от предыдущего результата; одна правка на запрос; фиксировать промпт и результат; сравнивать с оригиналом при одинаковом размере. Отклонять результат при уходе света, контраста или способа изображения. Автоматическая повторная генерация без проверки не даёт гарантии.

Использован встроенный imagegen. Исходники Venice сохранены. Пробы не подключены в игру. `comparison.png` — исходник и результат GPT для каждой пары.
