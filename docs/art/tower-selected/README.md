# Башня — 05 «Монтажный пролёт»

Самостоятельный интерактивный HTML-прототип выбранного владельцем направления. Это визуальная и интерактивная разработка, не Godot/runtime и не изменение игры.

Откройте `index.html` напрямую в современном браузере. Все изображения встроены как data URI, CSS и JS встроены; сеть, backend, storage и зависимости не используются. Пересборка: `node docs/art/tower-selected/build.cjs` из корня репозитория. Генератор читает существующие runtime PNG (64 px), SVG и архитектурный фон из `../tower-seven/assets/`; исходный kit и семь вариантов не изменяет.

Главный объект — выбранный этаж в центре. Слева всегда доступны пять этажей, снизу восемь активностей; справа выбранная инвентарная активность и двенадцать расходников. Установленная активность этажа и выбранная в каталоге активность показаны отдельно. Основное действие подписывает источник и цель. Холодный металл, charcoal, ivory и существующие lilac/pale yellow/white изображения продолжают вариант 05; выбранность обозначена замкнутой линией гнезда, клавиатурный фокус отдельными угловыми метками.

## Поведение

- Начало и «Сбросить демо»: ранг 8, по 5 экземпляров каждого вида, пять пустых этажей, выбран этаж 2 и «Прорывы» (`waves`).
- Клик по этажу/активности меняет выбор. Tab, Shift+Tab, Enter и Space работают на нативных кнопках. Стрелки и Home/End меняют выбор внутри групп; hover ничего не применяет.
- Установка переносит ровно один экземпляр на выбранный этаж. Замена возвращает прежний вид в каталог. Снятие возвращает экземпляр и освобождает этаж.
- Для каждого вида сохраняется `число в каталоге + число установленных = 5`. Установка того же вида или отсутствующего экземпляра недоступна с пояснением; снятие пустого этажа недоступно.
- Все счётчики и подписи обновляются сразу. Изменение маршрута объявляет `aria-live` область рядом с основным действием. У селекторов есть `aria-current`/`aria-pressed` и видимый клавиатурный фокус.
- Расходники выбираются, чтобы увидеть название. Crafting пока не подключён; применения, random, прогресса забега и фальшивого успеха здесь нет. Их количества остаются 20.
- Состояние существует только в памяти страницы. Перезагрузка сбрасывает его.

## Проверка и границы

Целевые размеры: 1280×720 и 1600×900; на 390 px допускается вертикальная прокрутка. Интерфейс адаптируется без декоративных анимаций, с учётом reduced motion. Основной текст не меньше 12 px.

Стабильные селекторы: `[data-floor="1"]`…`[data-floor="5"]` (также `data-installed="<id>"` либо пустая строка), `[data-activity="<id>"]`, `[data-count="<id>"]`, `[data-currency="<id>"]`, `[data-action="install"]`, `[data-action="remove"]`, `[data-action="reset"]`.

Авторские проверки: `node docs/art/tower-selected/build.cjs` и `node --check docs/art/tower-selected/build.cjs` — пройдены.
