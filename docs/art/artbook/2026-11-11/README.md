## Повторная сборка

Запустить build_artbook.py существующим bundled Python с Pillow/reportlab. Он читает текущий worktree и основную рабочую копию (корни указаны в скрипте/реестре), создаёт PDF и обновляет реестр. Отрендерить PDF через pdftoppm в tmp/pdfs/artbook/final-pages/page-*.png; запустить verify_artbook.py для проверки и21обзорного листа. Промежуточные рендеры остаются в tmp и не входят в ветку.
