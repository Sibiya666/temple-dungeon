# Стартовый кицуне в отладочной комнате

Дата: 2026-10-31. Статус: готово; независимый технический ревьюер APPROVE финальной версии, интерактивная комната запущена.

Поручение владельца: «Добавь китсуне на отладочную сцену». Выбран стартовый образ base из серии трёх моделей кицуне. Подмена касается внешности героя; класс и правила боя остаются текущими.

Предыдущая запись `characters.hero`: `apostate/ronin/ronin-room.glb`, height `1.85`. Ронин сохранён для возврата. Новая запись: `rogue/kitsune/kitsune-room.glb`, height `1.85`. Исходный GLB имеет высоту 1,8 м; сцена масштабирует его до прежнего целевого роста героя 1,85 м. Это техническая величина для комнаты, а не утверждённый рост народа.

## Проверка результата

Технический художник подготовил `spike-3d/briefs/rogue-kitsune/integration/kitsune-room.glb` с семью встроенными текущими hero-клипами Ронина. Модель скопирована в `assets/rogue/kitsune/` и соответствующий новый путь `game/vendor/`; полный sync не запускался, чтобы не удалять чужие vendor-файлы.

- `dotnet build game/Dialoid.Game.csproj --no-restore`: PASS, 0 предупреждений и ошибок (`build.log`).
- `godot --headless --editor --path game --import --log-file ...`: импорт нового GLB успешен (`import.log`). Sandbox препятствует сохранению глобальных editor settings и чтению root certificates; ошибка не относится к импорту ассета.
- `DIALOID_SELFTEST_FILTER=room`: 13/14, тот же единственный `room.shadow-budget` FAIL, что до замены (`room.log`; предварительный GLB, до сохранения вертикальной траектории прыжка).
- `DIALOID_SELFTEST_FILTER=combat.input-and-move`: 2/2 PASS (`movement.log`).
- `DIALOID_SELFTEST_FILTER=combat.skill-animations`: 2/2 PASS (`animations.log`).
- Оконный `DIALOID_SELFTEST_FILTER=room.animated-grounding` с `--selftest --screenshots`: 2/2 PASS, 35 замеров семи клипов (`window.log`).

Кадр настоящей сцены 1600×1000 под игровой камерой с HUD: `kitsune-in-room.png`. Он скопирован без обработки из `review/review/task-ronin-grounding.png`; историческое имя задаёт существующий selftest, код не менялся.

Финальная версия ассета: SHA256 `2A8D2671B39F79148B1002E00DC70BA4419BED7C19FFD90A385EF93EB5F1040A`. После независимой проверки переноса исправлена вертикальная траектория `hero_attack`: сохранён исходный прыжок, прежнее прижатие всех кадров к полу удалено. Финальный GLB заново скопирован в assets/vendor и импортирован. На этой версии повторены оконные 35 замеров grounding, обе целевые combat-проверки и кадр. Например, в `hero_attack` при 25%/50% длительности нижняя точка меша находится на 0,244/0,217 м над полом, а не искусственно на полу.

Проверка grounding устанавливает отсутствие проваливания в выбранных позах, но не доказывает правильность всех анимаций и смешивания клипов. Кости хвоста/ушей отсутствуют. Игровые механики роги и восхождений этим подключением не реализуются.
