# Инструкция Claude для этого пакета

Этот архив объясняет опыт создания изображений Dialoid; его чтение не является поручением запускать API, генерации или менять проект друга.

1. Прочитай `START_HERE.md`, затем `PROCESS.md`, `PROMPTS.md` и `CHECKLIST.md`. Просмотри нужные PNG, а не только подписи.
2. Назови реальные инструменты своей среды. Не считай, что у тебя есть встроенный GPT imagegen из чужой сессии Codex. Если инструмента нет, подготовь бриф для ручной передачи владельцем.
3. Маршрут этого процесса: концепты/задники — Venice; иконки — GPT от утверждённых оригиналов Venice. Не подменяй провайдера из-за удобства.
4. Художественный стиль примеров не навязывай новому проекту. Выбери с владельцем его собственный эталон; различай новый самостоятельный концепт и узкую вариацию.
5. На каждый вариант передавай оригинал семейства. Не строй цепочку перегенераций и не обещай детерминированности.
6. Сохраняй мастер, референс, промпт, происхождение и точный ID; экспорты отдельно. Рамки и состояния оставляй UI.
7. Показывай64/32/24 px. Проба не равна runtime-ready; подключение требует настоящего UI и проверки точного ресурса.
8. Для нового игрового контента учитывай индивидуальную смысловую иконку каждого навыка/узла в его задаче. Не скрывай долг общим символом.
9. Скрипт Venice получает только собственный ENV-ключ друга. Не проси ключ в чате, не печатай его и не отправляй никакие примеры в сервис без действующего поручения.
10. После неоднозначной ошибки платного вызова выясни состояние до повтора. Расходы, доступы и коммерческие права не наследуются от автора этого пакета.

Для нескольких исполнителей назначь отдельные файлы художнику, интегратору и независимому ревьюеру. Если независимый агент недоступен, честно назови проверку самостоятельной. Не откатывай чужие правки.

Пакет содержит учебные изображения, переносимые скрипты и необязательный skill. Скрипты проверяются офлайн; проверка live API/актуальных моделей и условий использования остаётся отдельным этапом.
