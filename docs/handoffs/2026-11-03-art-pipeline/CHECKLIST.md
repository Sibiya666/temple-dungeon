# Приёмка: от пробы до игры

## Перед генерацией

- Назначение и точный ID известны; новый концепт, вариант, задник и иконка не перепутаны.
- Выбранный PNG просмотрен глазами, его роль понятна.
- Записаны предметная замена и сохраняемые свойства.
- Концепт/задник отправляется в Venice; иконка — GPT от выбранного оригинала.
- Инструмент действительно доступен; есть свой доступ и согласованный объём расходов.
- Промпт сохранён до вызова, мастер получает новое имя.

## После генерации

- Просмотрен каждый мастер: смысл, силуэт, материалы, свет, цвет, поля и обрезанные края.
- Нет лишних надписей, UI-состояний, общей зернистости, случайных объектов или нового glow.
- Серия различима по силуэтам; общая форма не выдана за индивидуальные рисунки.
- Сохранены оригинал, точный референс, промпт, сервис/модель и параметры.
- Статус blur честный: true отклоняется, отсутствие данных не заменяется false.
- Отклонения от оригинала записаны; не обещана пиксельная идентичность.

## Перед выбором владельца

- Есть лист64/32/24 px в настоящих размерах; служебные знаки проверены и в16px.
- Мастера не перезаписаны экспортами.
- Для прозрачных объектов проверены alpha, отверстия, кайма, светлый/тёмный фон.
- Задник имеет спокойное поле под реальные элементы.
- Показан конкретный результат; авторская проверка не названа независимым ревью.

## Перед runtime-ready

- Владелец выбрал конкретные картинки; объём подключения понятен.
- Подключены точные ID, для дерева — `skill_id/node_id`.
- Каждый новый навык/узел получил собственную иконку; fallback не скрывает долг.
- Ресурсы попадают в экспорт игры, не зависят от компьютера художника.
- Настоящие слоты/каталог/дерево/HUD показывают выбранные картинки.
- Проверены кадрирование, клавиши, числа, cooldown, фокус и состояния в затронутых местах.
- При изменении кода пройдены соответствующие проверки; старые ошибки отмечены отдельно.
- Тесты изолированы от сохранений игрока.
- Независимый куратор подтвердил именно runtime-объём, а не только большой мастер.
- Проверены права/условия сервисов для предполагаемого использования.
