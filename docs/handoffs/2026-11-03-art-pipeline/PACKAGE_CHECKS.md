# Проверка пакета

Дата: 2026-11-03. Среда проверки: Windows, PowerShell7.6.5.

- Независимый экземпляр handoff_review прочитал документы, skill, примеры и критичные части скриптов. Вердикт APPROVE для передачи исходников пакета; автор отдельно проверяет собранный архив.
- Переносимые Markdown-ссылки проверены по существующим файлам. JSON-метаданные примеров разрешаются внутри пакета; активные ссылки не требуют исходного репозитория.
- Текст проверен на личные абсолютные пути и токеноподобные значения. В архив отбираются только документы, скрипты и примеры; `.env`, ключи, сертификаты, логи, пользовательские профили и исходная игра не включаются.
- 24 исходных изображения/промпта скопированы точно; SHA256 в `examples/copy-hashes.json`. Очищенные метаданные референсов сохраняют цепочку UI Venice → меч Venice → осколок Venice → иконки GPT.
- Скрипт контактов проверен офлайн: пять мастеров сохранены,15 экспортов64/32/24 совпадают с принятыми проектными PNG. Отрицательный сценарий запрещает экспорт внутрь мастеров. См. `examples/VERIFICATION.md`.
- Venice-клиент проверен офлайн: parser без ошибок,9/9 сценариев; сетевой вызов был заблокирован в тестовой среде, обращений — 0. Дополнительно выполнена команда DryRun из START_HERE. Новые генерации, расходы и проверка live API не выполнялись.
- Скрипт Venice проверяет структуру PNG, но не является полным декодером/CRC-проверкой. Live endpoint, доступность моделей, стоимость и коммерческие права не подтверждены.
- `BUILD_PACKAGE.ps1` создаёт `MANIFEST.sha256` и архив по явному списку каталогов, исключает `outputs/`, не перезаписывает существующий архив, затем сверяет SHA256 каждого ZIP-элемента с исходником. Манифест перечисляет все файлы пакета, кроме самого себя.

## Повторить локально

Офлайн-экспорт: команда из `examples/README.md`. Пересборка ZIP из корня пакета:

```powershell
pwsh -NoProfile -File ./BUILD_PACKAGE.ps1 -Out ../my-art-pipeline-copy.zip
```

Успех обозначается `PACKAGE_OK`; существующий архив требует другого имени. Подключение Venice или GPT для этих операций не нужно. Venice-клиент на реальных запросах требует собственного доступа; он не выполняется упаковщиком.
