# Как мы создаём изображения и иконки: пакет для друга и Claude

## Что внутри

Переносимый разбор реального процесса Dialoid на 3 ноября 2026 года: **Venice задаёт художественный оригинал → GPT делает предметные варианты иконок → малые размеры и настоящий игровой UI проверяются отдельно**. Пакет ничего не генерирует при открытии и не содержит наших ключей или настроек.

- [PROCESS.md](PROCESS.md) — процесс, ошибки и ограничения.
- [PROMPTS.md](PROMPTS.md) — готовые шаблоны заданий.
- [CHECKLIST.md](CHECKLIST.md) — приёмка изображений и runtime.
- [CLAUDE.md](CLAUDE.md) — короткая инструкция для Claude.
- [Примеры](examples/README.md) — выбранные оригиналы, витражные иконки, задник и настоящий игровой кадр.
- [Скрипты](scripts/README.md) — переносимый клиент Venice и экспорт размеров.
- `claude-skill/game-art-pipeline/` — необязательный skill для Claude Code.

## Как передать Claude

Распакуй архив. Передай Claude `CLAUDE.md`, `PROCESS.md`, `PROMPTS.md` и нужные PNG из `examples/`. Если среда умеет читать ZIP целиком, можно загрузить архив; иначе используй распакованные файлы.

Первое сообщение можно скопировать:

> Изучи пакет как описание процесса. Сначала объясни цепочку Venice → GPT → проверка → игра и перечисли, какие инструменты реально доступны у тебя. Затем помоги адаптировать процесс к моему проекту. Ничего не генерируй и не подключай платные API без моего задания. Стиль Dialoid — пример, а не обязательный стиль моей игры. Не выдавай отсутствующий инструмент генерации за доступный.

Для Claude Code скопируй `claude-skill/game-art-pipeline` в `.claude/skills/game-art-pipeline` своего проекта и вызови `/game-art-pipeline`. Существующий `CLAUDE.md` проекта не перезаписывай: перенеси только нужные правила. См. официальные инструкции по [skills](https://code.claude.com/docs/en/skills) и [проектной памяти](https://code.claude.com/docs/en/memory), проверенные2026-11-03.

## Быстрый запуск

1. Выбери одну задачу: концепт, задник, иконка или курсор. Опиши назначение и размер в игре.
2. Выбери художественный оригинал. Для своего проекта сделай собственный; здесь есть учебные примеры.
3. Подготовь один запрос и оцени первый результат до массовой серии.
4. При наличии PowerShell7 проверь клиент без сети:

```powershell
pwsh -File ./scripts/venice.ps1 -Mode generate -PromptFile ./examples/backgrounds/ascendancy.txt -Out ./outputs/dryrun-scene.png -DryRun
```

`DryRun` не отправляет запрос. Реальный вызов потребует своего доступа Venice, переменной окружения `VENICE_API_KEY` и разрешённого бюджета. Картинки в архиве доступа к сервису не дают.

5. Для GPT нужен доступный инструмент image generation либо ручная передача брифа и PNG владельцу в среду с таким инструментом. Claude и skill сами не создают отсутствующее подключение.
6. Проверь64/32/24 px, затем настоящий UI. После выбора владельца подключай по точным ID.

## Что здесь является примером, а что правилом

Холодная башня, готика и витражи — **наш художественный выбор**. Друг может выбрать другой мир, свет и материалы. Переносимые принципы: выбранный оригинал, конкретные изменения, происхождение файлов, реальные размеры и различение пробы и подключённого ассета.

PNG — примеры процесса, а не набор с объявленной коммерческой лицензией. Перед выпуском проверь актуальные условия сервисов и права на входные референсы. Этот пакет лицензионных гарантий не даёт. Ключей, `.env`, подписок и личных профилей в архиве нет.
