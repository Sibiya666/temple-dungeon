# Примеры процесса 2D-арта Dialoid

Это небольшой учебный набор для личной передачи процесса. Он показывает как удачные, так и отклонённые варианты. Изображения созданы в проекте; набор не является новой коммерческой лицензией и не подтверждает права на сторонние материалы, видимые в игровом кадре. Оригинальные секреты, профили и машинные пути не включены.

## Пять принятых витражных иконок

Подпись «в игру не подключены» на контактном листе сохранена с момента художественной пробы. Позднее владелец выбрал пятёрку, её подключили и сняли настоящий игровой кадр, приведённый ниже. Это разные этапы одного процесса.

[Контактный лист](stained-glass/preview.png) показывает отдельные смысловые изображения существующих навыков: `cleave`, `battle_cry`, `fireball`, `ice_lance`, `spark`. Генерация — встроенный GPT imagegen, 2026-11-03. Каждый вариант сделан от одного утверждённого оригинала Venice, а не цепочкой от предыдущей генерации. Владелец одобрил пятёрку, затем она подключена в игру под точными ID.

| ID | Мастер | Точный промпт |
|---|---|---|
| cleave | [PNG](stained-glass/masters/cleave.png) | [TXT](stained-glass/prompts/cleave.txt) |
| battle_cry | [PNG](stained-glass/masters/battle_cry.png) | [TXT](stained-glass/prompts/battle_cry.txt) |
| fireball | [PNG](stained-glass/masters/fireball.png) | [TXT](stained-glass/prompts/fireball.txt) |
| ice_lance | [PNG](stained-glass/masters/ice_lance.png) | [TXT](stained-glass/prompts/ice_lance.txt) |
| spark | [PNG](stained-glass/masters/spark.png) | [TXT](stained-glass/prompts/spark.txt) |

[Санитизированные метаданные](stained-glass/masters/metadata.json) содержат только переносимые относительные ссылки, даты, провайдера, ID и статус `adopted`. Ссылки внутри JSON разрешаются от папки самого JSON (`masters/`). [Контрольные суммы копий](copy-hashes.json) позволяют проверить целостность файлов набора.

В `copy-hashes.json` поле `file` отсчитывается от корня распакованного набора, поэтому включает префикс `examples/`.

[Настоящий игровой кадр ледяного копья](runtime/ice-lance.png), Godot, 2026-11-03: выбранное умение, его дерево и HUD после подключения. Это доказательство использования конкретной картинки в UI. Остальные общие символы узлов на этом кадре не выдаются за индивидуально завершённые иконки.

## Офлайн-масштабирование

Из корня распакованного набора, в PowerShell 7 на Windows:

```powershell
pwsh -NoProfile -File ./scripts/build-contact-sheet.ps1
```

Результат по умолчанию — `outputs/contact-sheet/`: лист, PNG64/32/24 и манифест SHA256. Можно задать другие `-InputDir` и `-OutDir`. Скрипт не обращается к сети и не генерирует новую графику, не меняет палитру/свет и не перезаписывает мастера. `OutDir` внутри каталога мастеров запрещён.

Справочные пути исходного репозитория: `docs/art/icons/2026-11-03-stained-glass-skills/`, `docs/art/icons/2026-10-31-venice-full-backgrounds/`, `docs/art/cursor/2026-11-03-venice-358/`. Они не нужны для работы распакованного набора; все активные ссылки выше находятся внутри него.
