# HUD: первый проход оформления D2

Оригинальные SVG созданы для Dialoid; сторонние изображения, шрифты и игровые ассеты не используются.

`RoomHudTheme.Create(source)` — копия существующей темы с новым оформлением, прежними метриками и фокусом. `Panel()` и `Border()` возвращают независимые экземпляры `StyleBoxTexture` для отрисовки. У 9-slice рамок фиксированные углы: их нельзя использовать вместо layout-стиля с меньшими отступами. Для существующих контейнеров рамки рисуются отдельным `RoomHudDecoration` с `Follow`; он не участвует в их layout. `MouseFilter = Ignore`, `FocusMode = None`.

Демонстрация: запустить `res://Ui/Art/HudArtPreview.tscn` в проекте комнаты. Сцена загружает настоящий `Main.tscn`, применяет тему только для просмотра. Параметр после `--`: `--art-screenshot <абсолютный путь PNG>` сохраняет кадр и завершает процесс.

`--art-windows` открывает персонажа и скиллы. Preview сравнивает до/после геометрию всех видимых кнопок, слотов и окон и завершает процесс с ошибкой при изменении rect или minimum size. Проверено 2026-10-31: 16 элементов в основном кадре, 122 при открытых окнах — без изменений. Сборка без ошибок и предупреждений; скриншоты сохранены самим Godot.

Это автономный пакет для интеграции после приёмки Task12. Существующие `CombatHud`, `WindowHost` и компоненты `Ui/Hud` не изменены. Локальные подсветки нехватки ресурса, очереди и канала сохраняются. Глобальная тема не заменяет самописную отрисовку компонентов полностью: для итоговой версии их владелец явно подключает стили через API.
