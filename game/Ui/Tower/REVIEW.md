## API

Namespace `Dialoid.Game.Ui.Tower`; `public partial class TowerBoardView : Control`.
`Setup(string dataDirectory)` принимает корневой data/, загружает tower/. Повторный успешный Setup не выдаёт валюту заново.
`event Action? CloseRequested` вызывается кнопкой Закрыть; глобальные Esc/B/F6 и блокировка боя принадлежат интегратору.
Для selftest: `Data`, `Assembly`, `Wallet` (nullable до успешного Setup), `SelectedFloor`, `StatusText`, `TestCharacterLevel`;
`SelectFloor(int?)`, `SwitchRank(int)`, `SetFloorType(string)`, `ApplyCurrency(string)`, `ValidateForTest()`.
Null-цель означает всю башню. RemoveOne использует выбранное свойство в OptionButton.

Кошелёк создаётся один раз, по 20 единиц каждой валюты максимального уровня (безуровневые нормализует Core). Сборки кешируются по рангу; переключение туда/обратно сохраняет свойства, RNG и стоимость перемешивания. Сохранений нет.
Контролы не удаляются при действиях: обновляются тексты/состояния. FollowFocus включён у трёх независимых скроллов.
Проверка входа: RankRules.LevelAllows + TowerRun.TryEnter с новым TowerProgress и персонажем 60 уровня, без запуска мира. Открыт только ранг 1. Убер-босс не выдумывается; ожидаем NoUberBoss для полной сборки ранга 1.
Прогноз качества: Rewards.FloorQuality / SummitQuality без бонуса за отсутствие смертей. Награды не создаются.
Свойства форматируются из Name с подстановкой {v}; единицы и смысл берутся из каталога.
